Modified by The Lads: repackaged into Lads Core (com.thelads.core.v1_21_1.embedded.immediatelyfast) for
Minecraft 1.21.1. The mixin plugin also stands the copy down while the original ImmediatelyFast jar is installed,
the version string is fixed instead of read from the (absent) mod metadata, the platform service is created
directly instead of through ServiceLoader, and the class tweaker entries moved into Core's access widener.
Upstream 1.6.14 is written against Yarn names; its sources were migrated to Mojang names (Loom migrateMappings) and the
Yarn access widener entries were translated. Its deprecated public API (net.raphimc.immediatelyfastapi, a no-op on 1.21) is
left out. The nested Reflect library (net.lenni0451:Reflect 1.6.2, MIT) is bundled as upstream does. A small added mixin gives
the repackaged BatchableBufferSource the radar-icon hook Xaero's Minimap installs on ImmediatelyFast's original class.
Config file kept: config/immediatelyfast.json. The complete modified source files ship in this jar under
META-INF/lads-sources/immediatelyfast/v1_21_1.
