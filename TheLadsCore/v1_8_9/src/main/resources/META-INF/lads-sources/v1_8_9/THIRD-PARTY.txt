  Source: https://github.com/unimined/JvmDowngrader/tree/2.0.1
  The Lads Core classes shared with the other game versions are compiled for Java 21 and converted to Java 8 bytecode
  by JvmDowngrader at build time; the stubs it references are copied into the jar. To relink with a modified
  JvmDowngrader, obtain the corresponding Lads source and run from TheLadsCore:
    gradlew.bat build189
  with the modified JvmDowngrader version in TheLadsCore/v1_8_9/build.gradle, then replace mods/theladscore.jar.
  No signature or integrity check prevents installing a modified jar.
