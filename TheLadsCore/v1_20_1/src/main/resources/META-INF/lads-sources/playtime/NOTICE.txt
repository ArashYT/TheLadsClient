Modified by The Lads: repackaged into Lads Core as com.thelads.core.v1_20_1.embedded.playtime
(mixin config theladscore.v1_20_1.embedded.playtime.mixins.json). Changes for 1.20.1: the render
hooks take the row geometry from the vanilla render(...) arguments (WorldListEntry,
OnlineServerEntry) instead of the 26.x content accessors; the icon is drawn with GuiGraphics.blit
and a shader colour instead of the 26.x render pipelines; play time and world size are read in a
wrapper around the per-world summary task of LevelStorageSource.loadLevelSummaries (1.20.1 has no
makeLevelSummary) and moved to util/PlayTimeScanner; NBT file access uses the 1.20.1 NbtIo API;
the server play time table is synchronized. The Cloth Config/Mod Menu settings screen is not
included; the settings file config/worldplaytimereborn/config.json and the server play time file
config/worldplaytimereborn/servers_playtime.dat are unchanged. Everything stands down while the
original worldplaytimereborn mod is installed.
