Entity culling in Lads Core for Minecraft 1.20.1 (com.thelads.core.v1_20_1.embedded.entityculling)

An independent implementation written for The Lads Client 1.4.6 (Minecraft 26.x). It recreates the behaviour of the
Entity Culling mod (entityculling, by tr7zw) from its public description only: asynchronous occlusion culling of
entities and block entities hidden behind opaque blocks. No Entity Culling code was read, copied or paraphrased,
for 26.x or for this port. It stays inactive while the original Entity Culling jar is installed (plain Fabric jar, or
the Forge jar under Sinytra Connector).

This 1.20.1 copy was ported from the Lads 26.3 embedded copy (package com.thelads.core.v26_2.embedded.entityculling).
Modifications for 1.20.1, all written by The Lads: render hooks moved to EntityRenderDispatcher.shouldRender and
BlockEntityRenderDispatcher.render of 1.20.1 (no EntityRenderer.affectedByCulling, no Leashable; mob leashes are read from
Mob), the opaque-block test uses BlockState.isSolidRender(BlockGetter, BlockPos), the shader shadow pass is read from
Iris (net.irisshaders) or Iris/Oculus (net.coderbot) ShadowRenderingState by reflection, and a QA probe was added.

The ray caster in the occlusion package is the OcclusionCulling library by LogisticsCraft
(https://github.com/LogisticsCraft/OcclusionCulling, commit 7a346eabc5edcfdef31df3c21202c3c1473fb506), Copyright (c) 2021 LogisticsCraft,
MIT License (LICENSE beside this file). Modified by The Lads: relocated into this package; otherwise unchanged.
