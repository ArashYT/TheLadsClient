This copy is ported to Minecraft 1.20.1 from the Lads 26.3 embedded copy (which is derived from
the source above).

Modified by The Lads: ported from Kotlin to Java and repackaged into Lads Core as com.thelads.core.v1_20_1.embedded.capes (mixin config theladscore.v1_20_1.embedded.capes.mixins.json); the Fabric entrypoint became a Core-called init; everything stands down while the original capes mod is installed.
Changes for 1.20.1: the cape and elytra textures are swapped in PlayerInfo.getCapeLocation/getElytraLocation (26.x swaps the PlayerSkin record) and the lookup starts the first time a profile is seen to be valid (the validity result is cached); the cape layer's solid render type is replaced by the cutout one with a wrapped call to RenderType.entitySolid; GameProfile accessors, ResourceLocation, NativeImage and GuiGraphics calls follow the 1.20.1 API; downloads run on a cached daemon thread pool instead of virtual threads; the cape selector draws the vanilla player and elytra models directly (26.x renders a placeholder avatar through render states) and the skin customization screen gets a plain 20x20 icon button (no sprite atlas on 1.20.1).

The complete modified source is in META-INF/lads-sources/capes/v1_20_1 in this jar.
