The built-in HUD layout engine adapts Raised 6.0.0 source (26.2 Fabric) by yurisuika,
commit 4b6a3b8718316d681c3ae6832cdd19c3174a29a4, under LGPL-3.0-or-later.
Original source: https://github.com/yurisuika/Raised/tree/4b6a3b8718316d681c3ae6832cdd19c3174a29a4/versions/26.2-fabric
The LGPL and incorporated GPL are in assets/theladscore/licenses. Modified source
is supplied in this directory, without obfuscation. The accompanying Core JAR
provides the application classes needed to compile/relink modified library code.

To rebuild in the supplied Lads source workspace, replace the desired files in
TheLadsCore/v26_2/src/main/java/com/thelads/core/v26_2/feature/raised, then run
TheLadsCore/gradlew.bat build deploy -x test with Java25. The deployed Core JAR
is used by the standalone Lads launcher. To replace just library classes, compile
against this JAR, Minecraft26.2 and the pinned Fabric dependencies, then use the
JDK jar tool to replace the resulting raised package classes/resources in a copy
of Core. Preserve unrelated entries, including bundled dependencies. The Lads
source has no signature or anti-modification restriction on this library.

Changes: relocated implementation classes, Lads menu integration and master
switch, shared smooth hotbar selection path, preserved resource-pack namespace,
separate atomic Lads layout storage, preserved previous config on import/recovery.
No standalone Raised mod or separate launcher is required.
