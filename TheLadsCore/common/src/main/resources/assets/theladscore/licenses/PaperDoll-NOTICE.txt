Native Paper Doll includes code adapted from Fuzss Paper Doll 26.2.3:
https://github.com/Fuzss/paper-doll/tree/5968f6f523a2ddc46e5890bd47dc6a5d9bf48b29

The adapted PaperDollMotion, NativePaperDoll and PaperDollSubmitMixin source files
are licensed under the Mozilla Public License, version 2.0. A copy is included
as PaperDoll-MPL-2.0.txt beside this notice. Changes replace upstream configuration,
event and render-state dependencies with native Lads controls and HUD integration.

The exact corresponding modified Java source files are included in this same
JAR at assets/theladscore/sources/paperdoll/. A JAR is a ZIP archive: open it
with an archive utility to read/copy these sources. No charge or account is required.
The 26.2 artifact contains the native rendering source; every supported artifact
containing the shared timing class includes that class's corresponding source.

Upstream artwork/assets are not included. The doll uses the actual player's
Minecraft renderer, game resources, skin and equipment.
