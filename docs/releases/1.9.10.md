# Lads Client 1.9.10

Lads Client 1.9.10 introduces **The Lads SMP Reborn** (v0.2.2) in the launcher's **Experiences** tab, converts both **The Lads SMP Reborn** and **Zero SMP** to fast Modrinth/CurseForge CDN manifest installers, adds the **Keep UI Open** module and new **Resource Packs** compatibility toggles, improves **Hypixel** party/kill detection and real ping smoothing, and hardens client security and authentication.

## Highlights

- **New Experience: The Lads SMP Reborn (MC 26.3, Fabric 0.19.5).** One-click install, update, and launch from the **Experiences** tab with 237 mods including Alex's Caves & Mobs, BetterEnd, Biomes O' Plenty, Dungeons & Taverns, Farmer's Delight, Simple Voice Chat, and Sodium & Iris.
- **CDN Manifest Installer for Experiences.** Both **The Lads SMP Reborn** and **Zero SMP** now install third-party mods, shaders, and resource packs directly from official Modrinth and CurseForge CDNs with SHA-512/SHA-1 verification, shrinking pack archives by over 99.8%.
- **Custom `Lads SMP` (`ladssmp-0.2.1.jar`) Core Mod.** Consolidates 13 standalone QoL and server performance mods into a single zero-dependency jar with an 11-layer item disabler, progression rebalance, `/ladssmp` admin tools, and `/back` death recovery.
- **Keep UI Open, Resource Pack Filters & Hypixel Upgrades.** Added the **Keep UI Open** module (1.8.9, 1.20.1, 26.3), resource pack compatibility toggles, cosmetic kill-message detection for Auto Play Again, and smoother Mod API ping fallback.

## Added

- **The Lads SMP Reborn Experience Card (`ExperiencesView`)**: One-click install/launch, binary GB RAM selector (`8 GB` default), account switcher, multi-instance management, folder shortcut, and non-destructive reinstall for `lads-smp-reborn-26.3`.
- **Invite-only The Lads SMP Reborn**: the Experience card only appears for invited Microsoft accounts. Staff manage the list live from Discord with `/smp_invite add|remove|list` (no launcher update needed); the last answer is cached for offline use.
- **Keep UI Open Module (`1.8.9`, `1.20.1`, `26.3`)**: Prevents server close packets from closing chat or your own inventory (while still allowing chests/containers to close) and restores typed chat text if interrupted by death or loading screens.
- **Resource Packs Compatibility Options**: Added **"Ignore incompatible packs"** to hide packs built for other Minecraft versions and made **"No pack compat check"** a toggle across `1.8.9`, `1.20.1`, and `26.3`.
- **`Lads SMP` (`ladssmp-0.2.1.jar`) Custom Mod**: 11-Layer Item Disabler (`ItemDisabler`), 13 consolidated QoL features, and `/ladssmp` admin command suite.

## Changed

- **Manifest-Driven Experience Downloads (`ExperiencesService`)**: Converted `lads-smp-reborn-26.3` and `zero-smp-1.20.1` archives to `modrinth.index.json` manifests with concurrent CDN downloads, mandatory SHA-256 archive verification, and SHA-512/SHA-1 mod verification.
- **Authentication & Security Hardening**: Restricted local development/offline accounts strictly to debug builds, enforced mandatory checksum verification across browsed mod installs, patches, and fallback JRE runtimes, and hardened skin URL redirect validation.
- **Lads SMP Reborn pack**: 26 standalone mods (including `misctweaks`, `stackrefill`, `cartcam`, `netherportalfix` and the `collective`/`jamlib`/`almanac` libraries) are now built into The Lads Client and the `Lads SMP` mod. Every remaining third-party mod downloads from Modrinth or CurseForge; the pack itself is ~1 MB and ships no third-party jars or executables.
- **Faster Launcher Startup**: the published launcher is now precompiled (ReadyToRun), opening about twice as fast (~0.8 s vs ~1.5 s to the Home page). The startup update check no longer holds the loading screen for more than 1.5 s; a slower check finishes in the background and offers its update through the title-bar Update button.
- **Loading Screen Logo**: the Lads Client logo now has a soft breathing glow instead of zooming in and out.
- **Hypixel Auto Play Again & Real Ping**: Added SkyWars/Duels cosmetic kill message and party split detection, ensured `gg` sends before `/play` without leaking into the next match, and smoothed Mod API ping with automatic status-ping fallback when rate-limited.

## Fixed

- **Minecraft 26.3 Datapack Registry & World Load Crashes**: Fixed `RegistryDataLoader` failing on legacy `loot_table` and `justenoughbreeding` recipe files, resolved the `Biolith`/`TerraBlender` surface rule crash, and fixed the `ItemsDisplayed` + `MiscTweaks` disc loot collision on world load.
- **The Lads SMP Reborn install failure**: the pack's patched-mod list was written in a format the launcher could not read, so installs stopped before downloading. The pack builder now writes the format the launcher expects and refuses to bundle any jar it cannot find on Modrinth or CurseForge.
- **The Lads SMP Reborn: crash when breaking or right-clicking blocks**: Custom Nether Portals (built for 26.1.2) registered outdated Architectury block break/right-click listeners, so breaking a block crashed the world ("Exception in server tick loop"). `Lads SMP` now registers working listeners; custom-shaped and horizontal Nether portals light again.
- **The Lads SMP Reborn: random startup crash**: Custom Nether Portals' point-of-interest hook crashed the game when Alex's Mobs loaded first ("Registry Object not present: customnetherportals:horizontal_nether_portal").
- **The Lads SMP Reborn: 80–160 s freeze when joining a world or running `/reload`**: Bits & Balance rebuilt its slab/step item lists once per recipe; `Lads SMP` now builds them once (world join recipe reload ~12 s instead of ~157 s on the QA laptop; long enough before to trip a dedicated server's watchdog).
- **The Lads SMP Reborn: datapack load functions never ran**: a Farmhouse Decorations function that cannot parse on 26.3 made the whole `#minecraft:load` tag fail; it is now a harmless no-op.
- **The Lads SMP Reborn: server crash placing `simplytents:my_geo_block`** (`/setblock`, WorldEdit): the unused block no longer creates an invalid tent block entity.
- **Screenshot Viewer settings crash (26.3)**: the settings' text and color fields used a render class 26.3 moved, crashing the game as soon as they drew. The bundled config library is now built for 26.3.
- **Title Screen Footer Layout**: Clamped the `TitleScreenTheme` footer Switch button gap at `w=240` for 2-digit patch version strings (`1.9.10`).
