# Lads Client 1.13.29

Animated 3D items and UI held items on The Lads Network no longer skip or smear animations.

## Fixed

- Animated custom items (for example the Neutron Star) could show several animation frames on top of each other while Sodium's "Animate Only Visible Textures" was on. The Lads Network now turns that Sodium option off for you while you play there; your own Sodium setting is never changed and applies again as soon as you leave.
- Held custom 3D UI items (such as the Game Selector, crowns, and cosmetic tools) now play the smooth pullout/swap animation when pulled out instead of popping up instantly.
