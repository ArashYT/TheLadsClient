# Lads Client 1.9.16

Lads Client 1.9.16 fixes the **ViaFabricPlus button hidden under Discover Servers** in the multiplayer server list.

## Highlights

- **ViaFabricPlus button visible again (1.20.1 and 26.3)**: ViaFabricPlus puts its version button in the top right of the server list, exactly where Lads' Discover Servers button sat, so you could not click it. Discover Servers now moves to the top left whenever another button is in the top right, and stays top right otherwise.

## Added

- Nothing new.

## Changed

- **Discover Servers** (1.20.1 and 26.3): top right as before, top left when ViaFabricPlus (or any other button) uses the top right. Works with every ViaFabricPlus button position and after resizing the window.

## Fixed

- **ViaFabricPlus' version button covered by Discover Servers** on the multiplayer screen (1.20.1 and 26.3).
