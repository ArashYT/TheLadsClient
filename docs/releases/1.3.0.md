# The Lads Client 1.3.0

## Added
- Five launcher tools: favorite profiles, combined profile search/version filtering, duplicate settings into a new profile, export/import settings presets, and local profile checks for Java, memory, disk space and running games. Open **Profiles → More** for profile actions.
- Five native HUD modules for Minecraft 26.2 and 26.3: **Clock**, **Stopwatch**, **ItemCounter**, **ReachDisplay** and **ServerAddress**. Each uses the existing HUD editor, scaling and colors. The clock supports 12/24-hour time; the server label can be masked.
- Five in-game conveniences: copy coordinates to the clipboard, Overworld/Nether portal coordinates, low-durability alerts, inventory-full alerts and optional chat timestamps. Enable **ClientTools** and **PortalCoordinates** in the Right Shift menu. Bind coordinate copying and timer controls in Minecraft Controls; they start unbound to avoid conflicts.
- Five launcher UI improvements: short page fades, animated button feedback, a **Ctrl+K** command palette, a saved **Reduced motion** option, and non-modal action notices. Errors stay visible until dismissed; success notices close automatically.

## Changed
- Five optimizations: a cheaper layout path for ungrouped HUDs, cached text widths, potion snapshots refreshed once per player tick, resource-pack list caching, and an optional **ParticleBudget** module that limits decorative smoke, leaves and spores by distance and per-tick quota.
- Text measurements invalidate after resource/font reloads. Clock and timer strings update only when their displayed time changes.
- Profile presets copy game options, Lads configuration and mod toggle choices. They create independent settings; worlds remain shared. Presets do not bundle mods, worlds or launcher account files.
- New gameplay modules are opt-in. The new native game integrations support 26.2 and 26.3; existing 1.21.1 and 1.21.11 builds remain supported, with unavailable integrations hidden there.
- The original Lads Remastered launcher icon, full in-launcher wordmark, welcome-screen fixes, world organization and borderless fullscreen fixes remain included.

## Verification
- Launcher regression tests and a rendered minimum-size UI check cover profile actions, filtering, keyboard commands, reduced motion and notices.
- All four Core adapters build and deploy. Focused native 26.2/26.3 checks exercise actual chat, particle, attack, inventory, keybinding and resource-reload hooks and capture completed game frames.
- A targeted test reduces unchanged HUD text measurements from 1,000 to one and checks font/text invalidation. This is a measured reduction in repeated work, not a promise of a particular FPS increase.
- These are offline checks; online authentication, live multiplayer behavior and physical keyboard/mouse interaction were not tested in this release pass.

## Updating
- Setup-installed launchers receive the complete update at startup or their next scheduled check, then restart when idle.
- Older standalone EXE installations need **TheLadsClient-win-Setup.exe** once.

Research and the complete 25-item acceptance matrix are in `docs/CLIENT_IMPROVEMENTS_1.3.0.md`.
