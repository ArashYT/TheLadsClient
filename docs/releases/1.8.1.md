# Lads Client 1.8.1

Comprehensive multi-version release bringing 1.8.0 features to 1.8.9 and 26.2, multi-version Essential world hosting/inviting, CurseForge-style modpack management with one-click content discovery, module settings scroll persistence, complete module visual previews, mob effect potion HUD icons, FPS HUD cap exceptions, and 1.8.9 server list and Essential fixes.

## Highlights
- **Full Multi-Version Parity**: All 1.8.0 title screen features, virtual scale 3.0 layout, in-game version switcher, quit confirmation dialog, language globe button, multiplayer discovery tab, and server list styling are now fully available on **1.8.9, 26.2, and 26.3**.
- **Essential World & Party Retained**: Restored and preserved Essential's "Host World" and "Invite Friends" actions on the pause menu across all versions (1.8.9, 26.2, 26.3) with dynamic reflection fallbacks.
- **CurseForge-Style Modpacks Management**: Redesigned the modpack details screen in The Lads Launcher with clear CurseForge-inspired tabs (Overview, Mods, Resource Packs, Shaders, Datapacks), automatic detection of Minecraft version and loader, inline search and installation from Modrinth, and manual file import.
- **Version Switcher Precision**: Version switching in-game is strictly constrained to **1.8.9, 26.2, and 26.3**. Switching versions in-game now immediately syncs and updates the launcher's selected profile upon exit.
- **1.8.9 Server List Speed & Stability**: Overhauled the 1.8.9 server pinger to use an unbounded parallel thread pool and removed the legacy 1.6 blocking fallback socket timeout. Spamming refresh no longer freezes, stutters, or lags the client.
- **Essential 1.8.9 ICE Setup Fix**: Neutralized false-positive firewall blocking detection in Essential 1.8.9, resolving the "ICE setup failed. Contact support" connection error when joining worlds.
- **Potion Effects Icons**: Potion Effects HUD module now renders official mob effect sprite icons directly beside effect names across all supported client versions.
- **FPS HUD Cap Exemptions**: Added granular FPS HUD cap exceptions both within HUD settings and per-module ("Ignore HUD FPS Cap"), allowing exempt elements and external mods to render at full monitor refresh rate while background elements are capped.
- **Module Settings Scroll Persistence**: Navigating into and out of module settings cards in Lads Settings Screen now preserves catalog scroll position instead of snapping to the top.
- **Visual Previews Across All Modules**: All modules across all client versions now feature rich visual previews (Nametags, Hitboxes, MotionBlur, DynamicLights, DiscordRPC, BetterF3, ToolsHud, Paperdoll silhouette, and PotionHud).

## Added
- `QuitConfirmScreen189.java`: Native exit confirmation dialog for 1.8.9.
- `VersionSwitchScreen189.java`: Native in-game version switcher for 1.8.9 with launcher sync.
- `ServerDiscoveryScreen189.java` & `GuiMultiplayerMixin189.java`: Curated server browser tab for 1.8.9 multiplayer.
- `ServerListEntryNormalMixin.java`: Unbounded cached thread pool for fast concurrent server list pinging in 1.8.9.
- `OldServerPingerMixin.java`: Suppressed blocking legacy ping fallback in 1.8.9 to eliminate refresh freezing.
- `EssentialFirewallMixin189.java`: Fixed Essential 1.8.9 ICE setup failure.
- `drawPotionIcon`: Implemented in `GuiGraphicsExtractorLadsAdapter` (26.2, 26.3) and `GuiLadsAdapter` (1.8.9).
- `getActivePotions`: Implemented in `VanillaGameBridge26` and `VanillaGameBridge189` returning full `PotionEffectInfo` with durations, amplifiers, and sprite references.
- Modpack manager tabs in launcher: Mods, Resource Packs, Shaders, and Datapacks with automatic loader and version compatibility filtering.
- Granular FPS HUD cap exemption chips and module-level toggle.

## Changed
- Title screen in 1.8.9 updated with virtual scale 3.0, "Is the sever up?" branding, Language globe button, Friends, Replays, and Switch Versions button spanning the bottom row.
- Multiplayer server list background dirt/dark texture removed across 1.8.9, 26.2, and 26.3.
- In-game version switcher dropdown and launcher synchronization restricted strictly to 1.8.9, 26.2, and 26.3.
- `PauseScreenMixin` in 26.2 and 26.3 ensures Essential singleplayer Host World and multiplayer Invite Friends actions remain accessible.

- Fixed 1.8.9 server list becoming slow, laggy, and freezing when spamming refresh.
