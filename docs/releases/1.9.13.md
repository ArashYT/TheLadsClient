# Lads Client 1.9.13

Lads Client 1.9.13 is a small update: **automatic crash reports** so we can find and fix crashes, and **emotes that stay in sync** in Hypixel parties.

## Highlights

- **Automatic crash reports**: when the Lads Client crashes, the launcher sends the crash details to the Lads team so we can fix it, including the crashes that close the game with no error message.
- **Emotes in sync on Hypixel**: party members who joined Hypixel with different addresses (`mc.hypixel.net`, `hypixel.net`, `play.hypixel.net`) now see each other's emotes.

## Added

- **Crash reports** (launcher, client profiles only): after a crash the launcher uploads the Minecraft crash report, the Java crash file (`hs_err_pid*.log`), the Windows crash record for Java and the end of the game log. Your Windows user name, computer name and login tokens are removed first. Modpacks and Experiences are never sent, and a normal close is never sent.
- **Setting**: Settings -> "Send crash reports to the Lads team (client only)", on by default.

## Changed

- **Emote rooms** use the server's main domain, so every address of one network shares a room. Players on 1.9.12 who typed `hypixel.net` are already in the same room as 1.9.13 players.

## Fixed

- Emotes not showing for party members on the same Hypixel server when one typed `mc.hypixel.net` and another `hypixel.net`.
