# Lads Client 1.13.28

Game modes can now set up your game for you.

## Changed

- Servers using the Lads Client API can now set any Minecraft video, sound, chat or control setting, and any key binding (mod keys too), for the game mode you are in: for example clouds off in a lobby, fancy leaves in a maze, or a different key for an ability. Your own settings file is never changed, and everything goes back to your own values when you leave. Turn off "Let servers change my Lads settings" in Server Control to keep your own values.
