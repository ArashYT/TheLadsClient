# Lads Client 1.13.0

Lads Client 1.13.0 brings a Voxel Noir title screen redesign, instant in-game account switching across every supported Minecraft version without restarting, full client settings migration, and deep Lads Network integration.

## Highlights

- **Voxel Noir title screen**: a sleek layout over the live spinning panorama with live Lads Network status. Switch back any time with the **Legacy layout** toggle at the top of the screen.
- **Switch accounts without restarting**: swap Microsoft or offline accounts on the spot across 1.8.9, 1.20.1, 1.21.11, 26.2, and 26.3 from the title screen or pause menu.
- **Import from other clients**: migrate settings from Lunar, Badlion, Feather, LabyMod 4, Modrinth, CurseForge, Prism, MultiMC, vanilla, or any custom folder—with a 7-day Undo backup.
- **The Lads Network Hub**: launcher Play card with live player count, plus an in-game Network Hub for one-click warps to Lobby, Parkour, PvP Arena, PvP Duels, and SMP.

## Added

- **Client settings migration**: Lunar, Badlion, Feather, and LabyMod 4 import modules, HUD layouts, keybinds, video/audio, servers, and packs; Modrinth, CurseForge, Prism, MultiMC, vanilla, and custom folders import options, servers, packs, and RAM allocation. Other clients' accounts and tokens are never read.
- **Lads Network integration**: Network buttons in the title screen, pause menu, server list, settings, and friends list (with markers and Join buttons for friends on `mc.arashyt.ca`), plus optional launcher auto-join.
- **Nick Detector**: passively marks likely nicked players on Hypixel (`[Nick]`) without sending packets or revealing real names (off by default; gated behind the server safety warning).
- **Kill Banner assists toggle**: added an **Assists give banners** option (off by default).

## Changed

- **Server resource packs enabled by default**: server resource packs now default to **Enabled** across all versions, imported/merged servers, and the Network button so prompts never interrupt joins. Servers explicitly set to **Disabled** stay Disabled.

## Fixed

- **Assists triggering kill banners**: assists on Hypixel, The Pit, and PvP Arena no longer trigger kill banners unless **Assists give banners** is turned on, and world/lobby changes clear held deaths cleanly.
- **Auto Play Again leaving early**: dying in respawning modes (Bridge Duels, Capture The Wool, Wool Wars, Paintball, The Pit, Cops and Crims, Warlords) no longer queues the next game mid-match.
- **Microsoft live swap & title panorama**: hardened named-pipe token hand-off for long Microsoft tokens and fixed panorama spin on 1.20.1, 26.2, and 26.3.
