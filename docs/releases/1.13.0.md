# Lads Client 1.13.0

Lads Client 1.13.0 brings a new title screen, in-game account switching without a restart, settings import from other clients, and much closer ties to The Lads Network.

## Highlights

- **New title screen**: a new design with the real panorama behind it. Your old layout is one click away with the Legacy layout button at the top of the screen, and it remembers your choice.
- **Switch accounts without restarting**: pick an account in game and the client swaps to it on the spot. In a world or on a server it asks first, then leaves and returns to the title screen.
- **Import from other clients**: bring your settings over from Lunar, Badlion, Feather and more, from the launcher or in game.
- **The Lads Network, built in**: a one-click Play card in the launcher with live player count, plus Network buttons in the pause menu, the server list and the friends screen.

## Added

- **Settings import**: Lunar, Badlion and Feather bring mods, HUD, keybinds, video and audio settings, servers and resource packs. Prism and the vanilla launcher bring options, servers and packs, plus launcher settings. LabyMod, Salwyrr, PvP Lounge and MultiMC bring the basics only. You see what will change before anything is applied, and you can undo an import for 7 days. Accounts and tokens from other clients are never read.
- **Nick Detector**: marks players on Hypixel who are probably nicked. It is off by default and sends nothing to the server. Hypixel's rules do not clearly allow it, so it stays blocked there unless you turn it on yourself through the red warning screen.
- **Network buttons**: join from the pause menu and the server list. On the network, the pause button becomes Hub when the server supports it.
- **Friends on the network**: friends on The Lads Network get a marker and a Join button.
- **Auto-join option**: the launcher can join The Lads Network on launch. It is off by default.
- **Assists give banners**: a new Kill Banner option, off by default.

## Changed

- **Server resource packs**: now Enabled by default on every server and the Network button, so there is no prompt. A server you set to Disabled stays Disabled. The Prompt choice is no longer remembered and comes back as Enabled.

## Fixed

- **Assists firing kill banners**: hitting a player that someone else finished no longer shows a banner, unless you turn on the new option. On servers that send no kill message, a banner can show up to about 0.75 seconds later than before.
- **Auto Play Again leaving too early**: dying in Bridge and other respawning modes no longer sends you to the next game. Duels modes the client does not recognise wait for the game to end.
