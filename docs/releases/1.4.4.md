# The Lads Client 1.4.4

## Fixed
- **The HUD FPS limiter no longer makes the HUD flicker.** The cap (on at 60 by default) skipped drawing the HUD on frames between updates, so it blinked. Now the HUD is rebuilt at the cap rate and the last build is drawn on every frame. It stays on screen and its content updates at the chosen frame rate. This applies to every version.
- **Minecraft 1.8.9 launches again.** 1.4.2 added Essential and Resourcify to the 1.8.9 pack. Essential's 1.8.9 jar is a Forge tweaker with no mod metadata, so after downloading about 64 MB with no progress shown (the launch screen stayed on "Verifying Java 8...") the launcher refused it as "Wrong Fabric mod downloaded for Essential". Both mods are removed from the 1.8.9 pack until they are tested with OptiFine and the Lads Core. 1.8.9 still runs on Forge 11.15.1.2318 with Java 8.
- **1.8.9 keeps its own worlds again.** 1.4.2 linked the shared `.minecraft` saves, resource packs and shader packs into the 1.8.9 profile. Opening a newer world in 1.8.9 corrupts it, so these links are removed on the next launch (the shared content itself is untouched), and 1.8.9 uses its own folders and options.txt again. The server list is still shared.
- **Module settings arrows.** On a `< value >` option, clicking the left side now goes back and the right side goes forward. Before, both sides went forward. Right-click still goes back, and the left/right arrow keys still step through options on a focused option. This applies to every version.
- **The 1.8.9 Core refuses shared worlds again.** 1.4.2 also removed the Core's own guard (`SharedContentPaths.isolateWorldsAndPacks`). It is back, so the game itself never uses the shared folders either.
- **1.8.9 Raw Input no longer floods the log.** Loading JInput through Forge's class loader logged 55 "security seal" errors on every start. JInput now loads from the parent class loader, as LWJGL does. Raw mouse input still starts.
- The 1.8.9 window title shows the real Core version, not a hard-coded "1.4.2".
- The 1.8.9 catalog no longer registers "OldAnimations" and "Crosshair" as built in. No modules have those names, and 1.7 Animations and Crosshair Tweaks are not on 1.8.9 yet. Resourcify is listed as not included on 1.8.9 again.
- The 1.8.9 in-game self-test is updated for the HUD and gameplay modules added in 1.4.1 and 1.4.2. It passes again with 84 checks.
- Mod downloads at launch now show their progress on the launch screen, not just in the status bar.
- The launcher's "wrong mod downloaded" errors no longer say "Fabric" on Forge.
