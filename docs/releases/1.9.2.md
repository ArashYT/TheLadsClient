# Lads Client 1.9.2

Lads Client 1.9.2 is a performance release. Essential is gone from every version, the HUD redraws at 60 FPS by default, 3D skin layers only render up close, and a round of smaller fixes makes 1.8.9 noticeably faster, especially with many players on screen.

## Highlights

- **Much higher FPS on 1.8.9.** On the same test machine, empty-world FPS went up 75%, crowds up 89%, and HUD-heavy scenes more than tripled compared with 1.9.1.
- **Essential removed from every version.** Its buttons and rows are gone from the title, pause and multiplayer screens. If Lads installed it for you it is removed automatically; a copy you added yourself stays untouched.
- **HUD FPS cap on by default at 60.** The HUD is redrawn 60 times a second instead of every frame. Existing installs are switched once; a limit you chose yourself is kept.
- **3D skin layers within 8 blocks.** Players farther away show the flat vanilla layer. In the many-players benchmark this raised the frame rate by about 70% with 60 players and about 95% with 150.
- **Faster defaults on 1.8.9.** Vertex buffers, Fast Render and Fast Math are on by default; Render Regions and Smart Animations are on for new installs.
- **Hypixel mods in one place.** The six Hypixel modules now live in one "HYPIXEL Mods" module with an on/off switch each.

## Added

- **Combo sound volume**: a 0-200% volume slider in the combo sound trimmer, saved per sound.
- **Kill banner "Per life" modes**: two new Randomize choices keep one skin and variant until you die or the streak ends; the next life picks a different one.
- **Cheat-injection protection**: game launches refuse attach/agent debugging options, and a background check looks for known cheat client packages and disconnects with a clear message.
- **True borderless option (1.8.9)**: Borderless Fullscreen can match the monitor size exactly, which lets Windows skip a frame of display latency. The default is unchanged.
- **Faster launcher and game startup**: caches for mod and OptiFine file checks and for Java detection; the game no longer forces a full garbage collection on every world load.
- **Many-players benchmark (QA)**: an offline benchmark of 20, 60 and 150 simulated players used to measure these changes.

## Changed

- **Essential retired**: see Highlights.
- **HUD FPS cap**: on at 60 by default (was off).
- **3D Skin Layers distance**: 8 blocks by default (was 14). A value you changed is kept.
- **Nametags (1.8.9)**: the text shadow now draws only the shadow instead of a full extra text pass, with the same look; names and options are cached per tick.
- **Scoreboard, tab list, chat and HUD text (1.8.9)**: sorted lists, character widths, text and sizes are cached, so these cost much less per frame.
- **Culling (1.8.9)**: the occlusion culling thread uses much cheaper lookups and takes less CPU.
- **Hypixel safety checks**: the server address is checked once per server instead of on every module check.
- **Video defaults (1.8.9)**: VBOs, Fast Render and Fast Math on; Fast Render turns itself off while a shader pack or Better Resolution needs it, then back on. Fast Math is OptiFine's lookup-table maths and differs only microscopically.
- **Modern versions**: ModernFix and other bundled mods ship with safer performance defaults for 1.20.1 and 26.3 on new installs; your own settings are never overwritten.
- **Swing**: clicking during a Legacy Swing / 1.7 animation no longer cuts it off; it plays out and the next swing follows.
- **Clumps**: the on/off switch takes effect immediately.

## Fixed

- **1.8.9 would not start without 3D Skin Layers installed.**
- **Fast quit and disconnect**: leaving a multiplayer server no longer waits on the network.
- **Forge 1.8.9 library repair**: a partly written library file from a crashed launch is rewritten on the next start.
- **Minimised and unfocused windows**: the world is no longer rendered while the window is minimised, and the title screen panorama pauses when unfocused.

## Benchmark numbers

Measured on a laptop (Intel Core i7-9750H, GTX 1660 Ti, 8 chunk render distance, small window, uncapped), average FPS, v1.9.1 then v1.9.2:

| Scene | 1.9.1 | 1.9.2 |
|---|---|---|
| Empty world | 909 | 1586 |
| Crowd (50 players, 50 armour stands) | 183 | 345 |
| Dropped items | 189 | 233 |
| HUD, scoreboard and chat | 200 | 657 |
| Kill banner | 1018 | 1557 |
| Particles | 354 | 484 |

Your numbers will differ with your hardware and settings.
