# Lads Client 1.13.18

ModSync keeps a friend's-world modpack in step with the host, including mods the host removes.

## Highlights

- **Removed mods now leave the pack**: when the host removes or replaces a mod, a friend who joins again gets it removed from their existing "<world> - <host>" modpack (the game restarts once to do it).

## Fixed

- ModSync only added and updated mods; a mod the host dropped stayed in the friend's modpack.
- Applies to modpacks synced from this version on; a pack made earlier starts tracking at its next sync.
