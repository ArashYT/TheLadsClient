# The Lads Client 1.4.2

## Highlights
- **Tab List Module Enhancements:** Added player head skin rendering toggle, customizable online player count display, size scaling, and independent color/transparency controls for header, footer, player rows, and global tab background.
- **Chat Enhancements & Animated Links:** Toggle chat background, custom width/height sizing, smooth slide-in message animations, and interactive action buttons (`[Copy]`, `[Open File]`, `[Open Folder]`, `[Upload to Imgur]`) on screenshot capture notifications.
- **Scoreboard Number Hiding:** Toggle to hide red sidebar score numbers globally, plus a smart conditional toggle (`Hide Sequential Only`) that automatically hides arbitrary 1–15 sidebar order rankings while preserving actual counters and stats (kills, coins, health).
- **Animations & Visual QoL:** 1.7 Animations with Low Fire and Low Shield toggles; internal native 3D Skin Layers engine removing external mod dependencies and resolving Alex slim arm rendering and vanishing hat glitches.
- **HUD & GUI Polish:** Coordinates HUD with left-alignment and Show Biome toggle; state indicators for Toggle Sprint/Sneak with persistent sprint latch through inventory, chests, and pause menus; crash-safe Bossbar rendering; restyled client-themed Minecraft sliders; and version branding displayed across title screen and OS window title bar.
- **Minecraft 1.8.9 Profile Parity:** Full unified content directory (shared saves, resourcepacks, shaderpacks, and configs); automatic cleanup of legacy isolated folders on launch; bidirectional keybind and option synchronization preserving version-specific settings; Essential mod integration; suppressed CurseForge startup browser popups; and native Raw Mouse Input, Borderless Fullscreen, and Legacy Swing on 1.8.9.
- **Global Resourcify Integration:** Included across all supported client versions, defaulting downloads to the global `.minecraft/resourcepacks` folder with a toggle to save locally per instance.

## Added
- **Tab List Module Upgrades:**
  - `Player Skins`: Toggle player avatars/heads on or off in the tab overlay.
  - `Show Player Count`: Customizable player counter appended directly to the tab footer (`Online: {count}`).
  - Independent color & transparency pickers:
    - Global tab body background (`Global Tab Background`)
    - Header background (`Header Color`)
    - Footer background (`Footer Color`)
    - Player name row background (`Player Row Color`)
- **Chat Module & Screenshot Actions:**
  - `Chat Background`: Option to render chat text with transparent backgrounds.
  - `Chat Width` & `Chat Height`: Custom dimension controls for focused and unfocused chat windows.
  - `Message Animations`: Smooth animated slide-in transitions for incoming chat messages.
  - Clickable screenshot action buttons appended to in-game capture messages:
    - `[Copy]`: Copies the captured screenshot directly to the system clipboard.
    - `[Open File]`: Launches the default system image viewer for the captured file.
    - `[Open Folder]`: Opens the screenshot directory in Explorer/Finder.
    - `[Upload to Imgur]`: Asynchronously uploads the screenshot to Imgur and copies the link to clipboard.
- **Smart Scoreboard Number Controls:**
  - `Hide Scores`: Hide red sidebar numbers across all scoreboard lines.
  - `Hide Sequential Only`: Detects sequential server rankings (e.g. 15, 14, 13... or 1, 2, 3...) and hides them automatically, while keeping numbers when used as gameplay stats (kills, timer, player count).
- **Cosmetics & OldAnimations:**
  - `Low Fire`: Lowers the first-person burning overlay by 30% to improve field of view during combat.
  - `Low Shield`: Lowers the first-person shield model position by 25% for better forward visibility.
  - Built-in 3D Skin Layers: Fully native client implementation across all versions, eliminating external mod conflicts.
- **HUD Elements & GUI Improvements:**
  - `Coordinates HUD`: Left-alignment styling and `Show Biome` toggle.
  - `Toggle Sprint` & `Toggle Sneak` HUD previews showing active toggle states.
  - Minecraft Sliders: Re-skinned vanilla and modded sliders with custom client dark surface styling, sleek knobs, and centered typography.
  - Title & Window Branding: Title screen and OS window title bar display `The Lads Client 1.4.2`.
- **1.8.9 Feature Parity & Controls:**
  - `RawInput`: Hardware-level raw mouse polling via JInput, bypassing Windows cursor acceleration and pointer speed scaling.
  - `BorderlessFullscreen`: Undecorated desktop-sized windowed mode for smooth Alt-Tab multitasking without monitor mode switching.
  - `LegacySwing`: Locks equipped item progress during attack and swing to remove re-equip dipping.
  - Essential Mod support added to 1.8.9 client pack.
- **Resourcify Integration:**
  - Pinned and integrated across 1.8.9, 1.21.1, 1.21.11, 26.2, and 26.3.
  - Saves resource packs to the shared `.minecraft/resourcepacks` folder by default, with `LocalResourcePacks` profile toggle to store locally per instance.

## Changed
- **Unified 1.8.9 Instance Folder:** 1.8.9 now participates in full shared directory parity alongside modern versions (sharing worlds, resource packs, shader packs, servers, and configurations).
- **Smart Options Synchronization:** Bidirectional translator converts keybinds between modern string keys and LWJGL2 integers during launches and exits without overwriting version-exclusive settings.
- **Installed Mods Filter:** Shift-menu Installed Mods tab defaults to `Enabled` mods for the active game instance.
- **Launcher Banner:** Reduced banner height in the Play view to 54px for a cleaner, more spacious layout.

---

## Fixed
- Fixed Toggle Sprint resetting to walking whenever opening inventory, containers, chests, or pause menus.
- Fixed 3D Skin Layers rendering glitches on slim (Alex 3px) models and vanishing hat outer layers.
- Fixed Bossbar rendering and crash exceptions across versions through thread synchronization and null safety.
- Fixed CurseForge web page automatically opening in the system browser upon 1.8.9 Forge startup.
- Fixed HUD frame rate cap throttling to respect configured FPS limits on all elements.
