# Lads Client 1.8.4

Interactive 3D skin model preview with 3D skin layers, native External Instances support (CurseForge, Modrinth, Prism, MultiMC), cross-version Controls synchronization, redesigned responsive Worlds, Servers, Profiles, and Gallery tabs, and built-in text editor and image viewer in the Files tab.

## Highlights
- **16:9 Launcher Window Size**: Slightly increased the default launcher dimensions to 1280×720 (minimum 960×540) to maintain a crisp 16:9 aspect ratio and offer ample room for multi-column responsive cards.
- **Interactive 3D Skin Viewer**: Replaced the static 2D preview in the Skins tab with a software-rasterized 3D player model. Supports 3D Skin Layers (extruded voxel outer layer), interactive mouse drag-to-rotate, scroll-wheel zoom, view reset, and live cape rendering.
- **External Instances (Modpacks)**: Added the **External Instances** sub-tab under Modpacks. Automatically detects CurseForge, Modrinth App, Prism Launcher, and MultiMC instances, allowing players to launch them natively through their respective external launchers without configuration tampering or profile sync interference. Custom launcher folders can also be imported.
- **Controls & Keybinds Synchronization**: Unified controls and keybind synchronization across all standard Lads Client profiles (`26.3`, `26.2`, `1.21.11`, `1.8.9`) via `SharedControls`, including bi-directional LWJGL 2 (1.8.9) to modern LWJGL 3 keycode translation.
- **Redesigned Worlds Tab**: Converted the worlds list into modern responsive cards with decoded `icon.png` thumbnails, `level.dat` metadata (game mode, formatted last-played timestamps, version chips), and clean action buttons.
- **Redesigned Servers Tab**: Split the Servers area into two dedicated sub-tabs (**My Servers** and **Browse**) styled with unified pill tabs, live server favicons, and formatted Minecraft color MOTDs.
- **Redesigned Profiles Tab**: Completely overhauled the Profiles tab into responsive cards with version, mod loader, and Java badges, an active profile indicator, and a sleek settings isolation checkbox.
- **Redesigned Gallery (Screenshots) Tab**: Replaced fixed WrapPanel dimensions with a responsive auto-fitting grid that dynamically computes column counts to eliminate empty space on the right side. Includes an improved Sources flyout and an integrated full-screen zoom/pan image viewer.
- **Built-In Text Editor & Image Viewer (Files Tab)**: Files tab now features an in-app text editor with dirty indicator, Save (Ctrl+S), Revert, Find (Ctrl+F), and Word Wrap, plus an image viewer with zoom/pan and 1:1 pixel mode for inspection without leaving the launcher.
- **Mods Tab Selection Checkbox**: Moved the batch selection checkbox inside the top-right corner of each mod card, directly above the action buttons.
- **Unified Design System**: Clean segmented pill tabs (`TabControl Classes="pills"`) and cohesive card/chip styles throughout the launcher interface.

## Added
- `TheLadsLauncher/Controls/SkinModel3D.cs`, `SkinMesh.cs`, `SkinRasterizer.cs`: 3D player model renderer supporting extruded outer voxel layers, camera manipulation, and cape rendering.
- `TheLadsLauncher/Services/ExternalInstances.cs` & `ExternalInstancesTests.cs`: Multi-launcher scanner detecting CurseForge, Modrinth (app.db SQLite / JSON), Prism Launcher, and MultiMC instances with native execution commands.
- `TheLadsLauncher/Services/SharedControls.cs` & `SharedControlsTests.cs`: Options and keybinding synchronization with legacy LWJGL 2 keycode translation for Minecraft 1.8.9.
- `TheLadsLauncher/Views/FileEditorView.axaml(.cs)` & `TextFileCodec.cs`: In-app text editor and image viewer.
- `TheLadsLauncher/MainWindow.Files.cs` & `MainWindow.Gallery.cs`: Extracted, modernized partial classes for Files and Gallery pages.
- Memory allocation slider in GB with quick presets (`Default`, `4 GB`, `6 GB`, `8 GB`, `12 GB`, `16 GB`) in the Modpack instance Overview page.

## Changed
- Bumped launcher and core version references to `1.8.4`.
- Updated default launcher dimensions to `1280×720` with strict 16:9 ratio enforcement.
- Updated `Styles/LauncherTheme.axaml` with standardized `.pills`, `.card`, `.chip`, and `.icon` classes.
- Mod cards place selection checkboxes inside the card at the top-right corner above `Disable`.
