# Lads Client 1.14.5

Multiplayer connectivity.

## Added

- Connection Tuning (Performance, on by default): the game connection to a server now sets TCP_NODELAY, TCP keep-alive and a low-delay traffic class on 1.8.9, 1.20.1 and 26.3. Dead connections are noticed sooner and small packets are not held back. Nothing changes in what is sent to the server.
