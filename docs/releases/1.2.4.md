# The Lads Client 1.2.4

## Added
- Launcher Worlds page with Global .minecraft, Specific Version and Custom Instances location filters, last-saved Minecraft version filtering, case-insensitive search and Reset filters. It reads world names and timestamps from level.dat, shows metadata errors without hiding the save, and opens the actual world folder.
- Add instance folder registers an existing custom instance for browsing without importing or moving its saves. Shared profile junctions are resolved so the same collection is listed once under Global .minecraft.
- On Minecraft 26.2 and 26.3, the singleplayer world list has a World folders button. The folder picker supports category filtering and instance-name/path search, followed by Minecraft's normal searchable world list. Folder choices use the actual save root; Minecraft retains its locking, backup and newer-world warnings. The launcher supplies registered folders at the next launch.

## Fixed
- Controls on 26.2 and 26.3 use a consistent native search screen even when Controlling replaces the vanilla screen. Search modes: All, Name, Keybind, Category and Mod; binding filters: All, Conflicts and Unbound. Category headings remain attached to matching rows. Mod search uses binding/category namespaces and installed mod names where ownership can be identified.
- The launcher title bar, both startup views, executable icon and tray/window icon use the complete Lads Client wordmark. Images keep their aspect ratio; Windows icons use transparent padding instead of cropping.
- 26.3 no longer disables Minecraft's Windows borderless-window implementation. Borderless fullscreen and return-to-windowed behavior were checked against the native SDL window; 26.2's existing GLFW implementation was checked as well.

## Storage behavior
- Existing 1.2.3 global sharing remains enabled. This update does not split or move existing worlds. A profile that points to the global saves folder appears under Global .minecraft; independent local folders appear under their own category. The version filter uses each world's last saved version, not a claim that it is safe to open in that version.
- Registering a folder in Worlds only adds a browsing source. It does not create a launcher profile or migrate that external instance.
- New game-side folder and controls UI is implemented for 26.2 and 26.3. The launcher world browser supports all profile versions; older game adapters retain their existing screens.

## Updating
- Setup-installed 1.2.1, 1.2.2 and 1.2.3 launchers discover this stable release at startup or on the next scheduled update check. The full package downloads automatically and installs when Minecraft and sign-in are idle, then the launcher restarts.
- Older standalone EXE installations and development copies need TheLadsClient-win-Setup.exe once. Use the installer-created shortcut afterwards. Accounts, profiles, worlds and settings remain outside the application update directory.

## Verification
- All four Core adapters built and deployed to the launcher bundles. Launcher build and self-contained Windows publish succeeded.
- 345 launcher tests passed, including world metadata/filtering, corrupt metadata, custom-source persistence and real shared-junction deduplication.
- Focused 26.2 and 26.3 game runs checked the active controls screen with click/character input, search reset, filter controls and resizing; 10 native borderless checks per version exercised two enter/exit cycles and restored window dimensions.
- Actual game framebuffer captures cover controls, the world list and folder picker. Launcher Worlds was rendered and visually inspected.
- Physical Alt-Tab and multiple-monitor movement were not tested. The full unrelated gameplay regression suites were not rerun.
