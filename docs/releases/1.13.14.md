# Lads Client 1.13.14

Faster game loading, shared mods in modpacks, and a title screen with a chat sidebar and a panorama picker.

## Highlights

- **Faster loading**: the game starts with better memory settings on Java 17 and newer, and ModernFix tuning now really reaches players.
- **Modpacks share their mods**: when a friend joins your world, the mods from your modpack come with the invite.
- **Title screen**: a chat sidebar for friends and a Panorama dropdown.

## Added

- **Modpack sharing (ModSync)** for Fabric modpacks: hosts publish their mod list, and guests get the missing mods before joining.
- **Panorama dropdown** and a **chat sidebar** on the title screen.
- **Large resource pack warning**: switching on a pack of 150 MB or more shows a notice, because it slows loading.

## Changed

- **Game memory**: a larger starting heap (at least 2 GB, never above your maximum), a bigger young generation and no string deduplication on Java 17 and newer. Version 1.8.9 keeps its own settings.
- **ModernFix**: the tuned defaults are now shipped and merged into your existing config without touching options you changed.
- **Modpacks button** no longer leaves you stuck on the Add Content page.

## Fixed

- **Title screen clicks on 26.3**: the chat sidebar and the Panorama dropdown ignored clicks.
- **Resource packs on 1.8.9**: the game no longer reloads when the pack list did not change.
