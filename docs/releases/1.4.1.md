# The Lads Client 1.4.1

## Highlights
- **Module Settings Redesign:** Two-column settings view with real-time interactive previews and eye-friendly soft ambient drop shadows.
- **Global HUD Frame Rate Cap & Counter:** Cap HUD render rates independently of game FPS (defaulting to 60 FPS [Recommended], with stepped snapping levels or direct custom entry) and monitor HUD vs Game FPS.
- **Launcher Polish:** Shrunk hero banner card, prominent glowing red gradient Play button with smooth hover scale effects, clean vector SVG icons, and a top-bar Update button.
- **Minecraft 1.8.9 Full Parity:** Ported all 26.3 gameplay and HUD modules to 1.8.9 Forge (Fullbright, ToggleSprint, ToggleSneak, Zoom, Crosshair, 3D Paperdoll, BossBar, ReachDisplay, ItemCounter, Clock, Stopwatch, ServerAddress, PortalCoordinates, and more).

## Added
- **Interactive Module Preview in Settings:** Opening any module in the Lads Settings menu displays a split 2-column layout—module options and sliders on the left, live high-fidelity preview box on the right.
- **Real-Time Module Synchronization:** Settings, scales, colors, and toggles persist and reflect across the game HUD in real time during dragging and adjustments.
- **Global HUD Frame Rate Cap:** Control the render refresh rate of the entire HUD (including vanilla HUD elements):
  - Stepped slider snapping strictly to predefined levels: `25`, `30`, `60 (Recommended)`, `75`, `120`, `144`, `165`, `180`, `240`, and `Unlimited`.
  - Manual text input field to configure any custom target frame rate limit.
  - Ability to enable/disable HUD capping independently of the Minecraft display FPS.
- **Global HUD FPS Counter:** FPS HUD module now supports displaying Game FPS, HUD FPS, or both simultaneously.
- **Eye-Friendly Soft Ambient Drop Shadows:** Refined global HUD shadow rendering with a softened multi-pass ambient glow instead of harsh drop offsets.
- **Launcher Header Update Button:** Added a dedicated "Update" button next to the title-bar minimize control that immediately polls for and handles launcher updates.
- **Refreshed Launcher Play Button & Navigation:**
  - Enlarged Play button featuring a vibrant ruby-red gradient, 1.04x smooth hover scale transition, and an active neon glow.
  - Crisp vector SVG iconography for Version Profiles, Mods & Packs, Screenshots, and Play controls—completely replacing emoji glyphs.
- **Minecraft 1.8.9 Feature Parity:**
  - Integrated built-in gameplay modules: Fullbright (gamma boost), ToggleSprint, ToggleSneak, Zoom, Custom Crosshair, 1.7 Animations / OldAnimations, and Legacy Swing.
  - Integrated HUD modules: 3D Paperdoll (via Forge `GuiInventory.drawEntityOnScreen`), Boss Bar (`BossStatus` hooks), Item Counter, Reach Display (raycast calculation), Autohide, Clock, Stopwatch, Server Address, and Portal Coordinates.

## Changed
- Compacted the launcher hero banner card on the Play screen to maximize visible layout space for profiles and status elements.
- Settings header controls now include quick shortcuts for toggling soft shadows and stepping HUD FPS limits.

## Fixed
- Fixed module settings not updating dynamically until menu closure.
- Fixed 1.8.9 HUD missing native rendering adapters for paperdoll and boss bar elements.
