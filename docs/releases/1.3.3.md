# The Lads Client 1.3.3

## Added
- In-game skin loading from a username, UUID, image URL or local PNG, with a native Windows file picker, model selection and reset. Skins are client-local; this does not upload a skin to your Minecraft account or change what other players see.
- World directory filters for **Global**, **This Instance** and **Other Instance**, plus **Add Folder** for mounting custom save directories.
- Global HUD colors in Core settings and the HUD editor, per-module overrides, a large color selector with alpha controls and favorite colors, and global background/text-shadow controls.
- A searchable paper-doll action selector with built-in player states and an integration registry for additional actions.
- Jade integrated into Core from the pinned upstream sources, retaining Jade's public API, addon discovery, registrations and protocol. Licenses, attribution and the integrated source are included. Native Autohide replaces the managed external Autohide module.

## Changed
- Default button styling follows the Lads title-screen design. The pause menu uses the same theme with the Lads logo at the top, and installed-mod entries show mod icons.
- Smooth scrolling in standard Minecraft scroll areas and Lads menus/settings. Essential menu actions are relocated into the Lads menus to avoid overlapping controls.
- Connected HUD widgets align to a shared width. The editor dock can collapse into an edge tab, expand on hover or click, and collapse after 1.5 seconds outside it.
- Paper-doll head pitch is locked in the Xbox 360 style. Default visibility triggers are crouching, sprinting, swimming and sitting/riding.
- Text shadows default to on. LMB/RMB CPS text is 35% smaller. **ToggleNametags** is now **Nametags**, with an option to hide the nameplate background.
- New native window, menu, skin, Jade and Autohide integrations target Minecraft **26.2 and 26.3**. The **1.21.1 and 1.21.11** builds remain supported and receive the shared HUD/configuration changes.

## Fixed
- Borderless mode uses the active monitor's full display bounds without native window borders and restores the previous window state when disabled.
- Previous/Next world-directory navigation and instance classification after switching save directories.
- Legacy Swing suppresses the vertical re-equip animation while preserving the crosshair attack-cooldown indicator.
- Skin-preview sizing/model rendering and support for extruded 3D outer skin layers in the preview.
- Autohide now fades the active hotbar-slot highlight along with the hotbar.

## Verification and limitations
- All four Core adapters build and deploy; 450 shared Core tests pass. Focused 26.2/26.3 runtime checks exercise the new features and capture completed game frames.
- An independent Jade addon passes discovery, tooltip and server-data callback checks. This is not a guarantee for every third-party addon or a remote-server protocol test.
- Native file-dialog selection/cancellation, physical multi-monitor/DPI transitions, live authentication and multiplayer were not manually tested in this release pass.
- Windows packages are unsigned and may show a reputation prompt.

## Updating
- Setup-installed launchers receive the complete update at startup or their next scheduled check and restart when idle.
- New users and older standalone EXE installations should use **TheLadsClient-win-Setup.exe**.
