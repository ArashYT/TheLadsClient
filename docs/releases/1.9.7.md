# Lads Client 1.9.7

Lads Client 1.9.7 syncs Lads Client settings and HUD layouts across all instances, refines the default HUD layout and module presets, gates Hypixel Mods to only activate on Hypixel, fixes 1.20.1 block texture shearing and HUD bar alignment, and adds six new mods to Zero SMP.

## Highlights

- **Cross-instance settings sync.** Your Lads Client settings, HUD layout, HUD profiles, and crosshair profiles now sync automatically across all version profiles and modpack instances where Lads Core is installed.
- **Zero SMP content update (`1.1.3`).** Added **Proper Ping**, **Miku Plushies**, **MCEF**, **Custom Jukebox Discs**, **WebDisplays**, and **Crawl** to both the Zero SMP client and server with pre-tuned configs and conflict-free keybinds.
- **Refined defaults & cleaner Modules menu.** Updated the default enabled modules, default HUD layout (including disabled element positions and anchor groups), and default module settings (`Chat`, `Nametags`, `Potion Effects`, `Scoreboard`, `TabList`), while hiding legacy non-Lads mod entries and keeping `TitleScreen` always active.
- **1.20.1 rendering & HUD alignment fixes.** Fixed 45-degree diagonal block texture shearing and restored vanilla relative spacing between the hotbar, XP bar/level, hearts, armor bar, and hunger bar.

## Added

- **Cross-instance configuration sync**: `thelads_config.json`, `thelads_profiles.json`, and `thelads_crosshair_profiles.json` are now resolved from the most recently modified file and mirrored across `shared/`, root `.theladsclient`, `profiles/*`, and `instances/*/minecraft` both at runtime and via the launcher.
- **Zero SMP 1.20.1 mods (`update-1.1.3.json`)**:
  - **Proper Ping** (`1.0.0`) — numeric ping in the Tab list (top-left HUD text off by default).
  - **Miku Plushies** (`2.0.1`) — craftable/collectible Miku plushies.
  - **MCEF** (`2.1.6`) & **WebDisplays** (`2.0.2`) — in-world browser screens with 30 FPS cap, GPU rasterization, spatial auto-volume, 10 MiB MiniServ quota, and simplified upgrade recipes (`[` to toggle laser/mouse).
  - **Custom Jukebox Discs** (`0.4.0`) — custom audio discs with headphone indicator and 512 MiB client cache (`I` to toggle playback).
  - **Crawl** (`0.12.0`) — dedicated crawling mechanic (`J` with toggle mode enabled), replacing `Crawl on Demand`.

## Changed

- **Hypixel Mods server gating**: `HYPIXEL Mods` can still be toggled and configured from the Modules menu at any time, but its runtime features (`AutoGG`, `AutoTip`, `AutoGL`, `LevelHead`, `NickHider`, `QuickPlay`, SkyBlock/BedWars overlays) only activate when connected to Hypixel across `1.8.9`, `1.20.1`, `1.21.11`, `26.2`, and `26.3`.
- **Modules menu cleanup**: Removed legacy third-party mod buttons (`Jade`, `EntityCulling`, `Jasione`, `Async`, `Exordium`, `XaeroWorldmap`, `JEI (Just Enough Items)`, `ScalableLux`, `NotEnoughAnimations`, `BetterStats`, `ModernAdvancements`, `Resourcify`, `Flashback Settings`, `Lithium`, `FerriteCore`, `XaeroMinimap`) from the Modules list, and made `TitleScreen` always active without a module toggle button.
- **Default modules, settings, and HUD layout (one-time 1.9.7 preset override)**:
  - Upgrading to 1.9.7 resets existing module states, module options, and HUD layouts once (`lads197PresetApplied`) to the new 1.9.7 default preset across all instances; any changes made after upgrading are saved normally.
  - Enabled the curated 51-module preset by default (`Kill Banner` on `Red Reaver`, `Toggle Sprint & Sneak` with sprint toggle only).
  - Set default options for `Chat` (`Chat Background = Off`, `Message Animations = On`), `Nametags` (`Render Background = Off`), `Potion Effects` (`On`), `Scoreboard` (`Background = Off`, `Hide Sequential Only = On`), and `TabList` (`Background = Off`).
  - Updated `HudSettings.resetToDefaults()` with the new default positions, anchors, and groups for all enabled and disabled HUD elements.

## Fixed

- **1.20.1 block texture shearing**: Disabled `ModernFix` `mixin.perf.dynamic_resources` in Zero SMP and added `FaceBakerySafetyMixin` in `v1_20_1` to clone `BlockFaceUV` arrays per quad during baking, preventing concurrent chunk-meshing threads from corrupting shared parent model UVs on stairs, slabs, and blocks.
- **Hotbar, XP level, armor, and hunger bar alignment**: Stopped embedded `HoveringHotbar` from double-lifting the hotbar/XP bar on top of `Raised` and removed its `+3` px XP level shift that pushed the level number between the hearts and hunger bars.
- **Experiences tab multi-instance controls**: Added the **PLAYING AS** account quick-switcher (`ZeroSmpAccountSelector`) and **Instances Open** dropdown + quick-close buttons (`Close Instance 1`, `Close Instance 2`, `Close Instance 3`, `Close All`) next to **Play Zero SMP**, and isolated the Dev Launcher's Zero SMP instance (`zero-smp-1.20.1-dev`) from the Regular Launcher's Zero SMP instance (`zero-smp-1.20.1`).
- **Multi-instance setting on Experiences & Modpacks tabs**: Fixed `"Allow launching multiple copies of the same instance"` in Settings not applying to the Experiences and Modpacks tabs, and prevented locked native/library files in `modpack-cache` from blocking a second instance launch.
