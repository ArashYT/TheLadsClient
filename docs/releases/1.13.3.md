# Lads Client 1.13.3

Lads Client 1.13.3 is a smaller update: typing works again in Friends on 26.3, the launcher and the game now share one account list with real skins, the server list gets a big upgrade, and buttons have new icons.

## Highlights

- **Your launcher accounts in game**: the in-game Account Switcher now shows the same accounts as the launcher, with each account's real skin.
- **A better server list**: side-by-side columns, the version of each server, a one-click version change for servers on another version, and a real preview when you move a server.
- **Right-click menus**: for servers and worlds.
- **New logo and icons**: the Blockbench logo on the title screen, now on two lines, and Flaticon icons on buttons in the launcher and in game.

## Added

- **Server list columns**: show 1, 2 or 3 columns with the new button on the Multiplayer screen. A count only shows when there is room for it at your window size and GUI scale, and the list comes back to your choice when there is room again.
- **Server version**: each server shows its version next to its ping and player count, in red when it does not match your game.
- **Change version for this server and reconnect**: a server on a different version gets this button. It sets ViaFabricPlus for that one server only, saves it and joins. It is on 1.20.1, 1.21.11, 26.2 and 26.3. 1.8.9 has no ViaFabricPlus, so it only shows the red version.
- **Right-click menus**: servers have Join, Edit, Delete, Copy address and Refresh, plus the version change when needed. Worlds have Play, Edit, Delete, Re-create, Open folder and Copy name. Deleting still asks you to confirm.
- **Remove accounts in game**: click the remove icon on an account row twice. The launcher removes it too.

## Changed

- **The Lads Network stays on top**: it is pinned first in the server list. It cannot be moved, edited or deleted there, and nothing can move above it.
- **Moving a server**: the whole server now follows your cursor and the list opens a gap where it will land, instead of a white line. Dragging servers now also works on 1.21.11 and 26.2.
- **Network button**: removed from the server list, since the network is pinned at the top. The title screen keeps its button.
- **Title screen**: the logo is now our Blockbench logo on two lines, in both the new and legacy layouts. The tagline is now "Built for the lads." The strip at the bottom shows your account's real head.
- **Icons**: buttons in the launcher and in game use Flaticon icons. Very narrow buttons, on/off toggles and buttons from other mods stay as they were.

## Fixed

- **Typing on 26.3**: you could not type in the Friends screen (Add Friend, messages, nicknames), the Host screen, Quickplay search or the HUD editor search. All of them work now, and opening the Add Friend tab lets you type straight away.
- **Title screen tooltips**: they appeared far from the cursor at some window sizes and GUI scales. They now sit at the cursor.
- **Accounts out of sync**: the game only learned about your accounts at launch, for that one game folder. It now reads the launcher's list each time the switcher opens.
- **Wrong skins**: account heads showed a default skin instead of the real one on every version. Older skins with a solid hat area also no longer draw a black square on the face.
- **Server list on 1.8.9**: the first time you opened it after launching, most servers said "Can't connect to server" until you refreshed. They now all answer the first time.
- **Account Switcher scrolling**: the mouse wheel now works on 26.3, 1.20.1 and 1.8.9, so long lists are reachable.
