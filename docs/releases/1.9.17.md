# Lads Client 1.9.17

Lads Client 1.9.17 tidies the **1.20.1 server list**: ReplayMod's **Record Server** checkbox no longer hides behind the ViaFabricPlus button.

## Highlights

- **Record Server checkbox visible again (1.20.1)**: ReplayMod and ViaFabricPlus both put their control in the top right of the server list, so the checkbox sat under the ViaFabricPlus button. On the server list it now sits bottom right, between the server list and the buttons.

## Added

- Nothing new.

## Changed

- **ReplayMod's Record Server checkbox** (1.20.1 server list): moved from the top right to the bottom right, just above the buttons. The world list keeps its Record Singleplayer checkbox where it was.

## Fixed

- ReplayMod's Record Server checkbox covered by the ViaFabricPlus button on the 1.20.1 multiplayer screen.
