# Lads Client 1.11.2

Lads Client 1.11.2 is a safety update. A full audit of the client found a few features that could make a server's anticheat flag you. They now follow the server rules like every other risky module: they work in singleplayer, on LAN and on servers that allow them, and stay off on servers that ban them and on servers whose rules we don't know.

## Highlights

- **Fewer ban risks** (1.8.9, 1.20.1, 26.3): Survival Tweaks, Dimension brightness, Keep UI Open, Auto Reconnect, Opened Chest Highlight, Boat 360 View and Xaero's World Map now follow the server rules, and servers reached through a proxy on your own PC count as unknown. Nothing changes in singleplayer or on LAN.

## Added

- Nothing in this update.

## Changed

- **Survival Tweaks** (1.20.1, 26.3): Faster obsidian mining, Berry bush protection and Elytra water swim change how fast you mine and move, which anticheats check. They now work only in singleplayer, on LAN and on servers that allow them. The other Survival Tweaks options work everywhere as before.
- **Dimension brightness** (Survival Tweaks): on servers that don't allow Fullbright it stops at vanilla's brightest setting.
- **Keep UI Open**: keeping the inventory open after the server closes it now follows the server rules; keeping chat open works everywhere.
- **Auto Reconnect**: follows the server rules of the server it reconnects to.
- **Opened Chest Highlight**: follows the server rules (it stays off on Hypixel). On 1.8.9 it no longer marks chests that other players opened.
- **Xaero's World Map** (1.20.1, 26.3): can't be opened where the server rules block minimaps. On 1.20.1 and 26.3 the minimap now stays off where it is blocked even if its Lads integration can't load, instead of showing anyway.
- **Servers on your own PC**: joining a server at localhost or 127.0.0.1 (for example through a proxy such as ViaProxy) now counts as an unknown server, because the real server behind it could ban. Your own worlds, worlds you open to LAN and servers on your home network work as before.
- **Boat 360 View** (1.20.1, 26.3): follows the server rules, because it sends head turns that vanilla limits in boats.
- **Lads Horizon** (launcher): if Lads Horizon was turned on without accepting the risk warning, it is turned off and the warning shows again next time you turn it on.
- **Clear Water** (1.8.9, OptiFine settings): follows the same server rules as Fog Customizer's Clear Water.
- **Real ping**: only measures while Ping HUD or Ping View is on.

## Fixed

- **Blindness and Nether fog** (1.8.9): custom fog settings no longer weaken Blindness, Nether or lava fog. The Fast fog option draws correctly again.
- **Servers with no server info** (1.8.9, 26.3): are now treated as unknown servers, not as singleplayer.
- **Server bypasses**: the list of servers where you allowed a blocked module is saved safely. A crash while saving, or one broken entry, no longer wipes the whole list.
- **Lads Horizon** (launcher): the Experimental setting is only saved after you accept the risk warning.
