# Lads Client 1.13.24

Experimental Lads Horizon (26.3) moves to the newest Horizon and is now plain Horizon with the Lads title screen.

## Highlights

- **Lads Horizon on the newest Horizon**: the experimental 26.3 build now comes from Horizon Nightly 2026-11-13 (was v0.2.97 from October), with everything Horizon added and fixed since. It downloads once on the next Play, then prepares itself again.

## Changed

- Lads Horizon no longer has the Lads HUD and Lads Zoom: it is plain Horizon with the Lads title screen, window name and icon. The old Lads HUD mod is removed from its folder by itself; your Horizon worlds and options stay.
- Lads Horizon still turns risky features (agent control, auto-reconnect, minimap, mouse tweaks, inventory sort, fullbright, mod chat and packets) off on servers that ban them or whose rules are not known. They cannot be turned back on per server in this build.
- The earlier Lads Horizon build is deleted from disk once the new one is installed.
