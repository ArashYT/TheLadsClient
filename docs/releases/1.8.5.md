# Lads Client 1.8.5

Added support for Minecraft 1.20.1 with 1:1 feature parity to 26.3, and introduced the Experiences tab featuring curated server experiences like Zero SMP.

## Highlights
- **Minecraft 1.20.1 Support**: Full runtime and module support for Minecraft 1.20.1 running Fabric Loader 0.16.10 and Java 17. Includes 50 verified client mods matching the 26.3 experience.
- **TheLadsCore 1.20.1 Subproject**: Complete native bridge and in-game HUD modules compiled for Minecraft 1.20.1 and Java 17.
- **Experiences Tab**: New Play sub-tab offering curated Minecraft server experiences (such as Zero SMP) with dedicated artwork, status, and direct launch flows.

## Added
- `TheLadsCore/v1_20_1/`: Fabric 1.20.1 subproject with `TheLadsCoreClient1201` and `VanillaGameBridge1201`.
- `TheLadsLauncher/game-mods/1.20.1/`: Bundled `theladscore.jar` and `client-mods.json` for 1.20.1.
- `TheLadsLauncher/Services/ExperiencesService.cs` & `Views/ExperiencesView.axaml(.cs)`: Experiences page.
- `TheLadsLauncher.Tests/ExperiencesServiceTests.cs`: Unit tests for experiences service.

## Changed
- Bumped launcher and core version references to `1.8.5`.
- Updated `ProfileTools.PlayableVersions` and `ProfileService` to include `1.20.1` as a default playable version.
