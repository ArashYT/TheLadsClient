# Lads Client 1.13.2

Lads Client 1.13.2 brings a new title screen, in-game account switching without a restart, settings import from other clients, and much closer ties to The Lads Network.

## Highlights

- **New title screen**: a new design with the real panorama behind it. Your old layout is one click away with the Legacy layout button at the top of the screen, and it remembers your choice.
- **Switch accounts without restarting**: pick an account from the title screen or pause menu, on every supported version, and the client swaps to it on the spot. In a world or on a server it asks first, then leaves and returns to the title screen.
- **Import from other clients**: bring your settings over from Lunar, Badlion, Feather, Modrinth, CurseForge, Prism, MultiMC and more, from the launcher or in game.
- **The Lads Network, built in**: a one-click Play card in the launcher with live player count, a Network button on the title screen, and a new Network screen in game with one-click trips to each server.

## Added

- **Settings import**: Lunar, Badlion and Feather bring mods, HUD, keybinds, video and audio settings, servers and resource packs. Prism, MultiMC and the vanilla launcher bring options, servers and packs, plus launcher settings. Modrinth and CurseForge bring options, servers and packs from your most recent instance, plus the RAM you set for it. LabyMod and any other folder you choose bring the basics only. You see what will change before anything is applied, and you can undo an import for 7 days. Accounts and tokens from other clients are never read.
- **More ways to import**: pick any client or game folder and the importer works out what it is. The in-game import is also in the Profiles window.
- **Network screen**: shows how many players are online and lets you join the network or jump straight to the Lobby, Parkour, PvP Arena, PvP Duels or SMP. Open it from the network status on the title screen or the Lads Network button in settings. Its server trips only ever send a command while you are on The Lads Network.
- **Nick Detector**: marks players on Hypixel who are probably nicked. It is off by default and sends nothing to the server. Hypixel's rules do not clearly allow it, so it stays blocked there unless you turn it on yourself through the red warning screen.
- **Network buttons**: join from the title screen, the pause menu and the server list. On the network, the pause button becomes Hub when the server supports it.
- **Friends on the network**: friends on The Lads Network get a marker and a Join button.
- **Auto-join option**: the launcher can join The Lads Network on launch. It is off by default.
- **Assists give banners**: a new Kill Banner option, off by default.

## Changed

- **ReplayMod's title icon on 1.8.9**: removed, since the title screen already has a Replays button.
- **Server resource packs**: now Enabled by default on every server and the Network button, so there is no prompt. A server you set to Disabled stays Disabled, and the Network button respects that too. The Prompt choice is no longer remembered and comes back as Enabled.
- **Joining the network from a button**: adds The Lads Network to your server list if it is not there yet.
- **Third-party modpacks**: choosing another account there applies at the next launch instead of on the spot, because only our own packs get the launcher's account connection.

## Fixed

- **Pit and arena kill streaks**: your own death in more server formats now ends the streak correctly, and other players' deaths do not.
- **Assists firing kill banners**: hitting a player that someone else finished no longer shows a banner, unless you turn on the new option. On servers that send no kill message, a banner can show up to about 0.75 seconds later than before.
- **Kill banners on 1.21.11 and 26.2**: changing world or lobby no longer leaves a banner behind, and these versions now match the others.
- **Auto Play Again leaving too early**: dying in Bridge and other respawning modes no longer sends you to the next game. Duels modes the client does not recognise wait for the game to end.
- **Account switching**: a switch that fails now tells you what happened and which account you are still on, and long Microsoft sign-ins hand over more reliably.
- **Nick Detector**: no longer marks you when you are nicked yourself or marks a name twice, and clears as soon as you turn it off or leave Hypixel.
- **Title screen panorama**: spins properly again on 1.20.1, 26.2 and 26.3.
