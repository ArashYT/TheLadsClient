# The Lads Client 1.2.5

## Fixed
- Restored the original Lads Remastered anime girl holding a pickaxe as the executable, taskbar, window, tray and installer icon. The full Lads wordmark remains inside the launcher.
- FancyMenu's introductory welcome screen is disabled before launching both new and existing profiles.
- Modpack Core Essentials now uses its NEVER welcome mode, including migration of older startup flags, so its default welcome message does not interrupt first launch or repeat launches.
- These changes preserve other mod settings and do not modify Essential account, onboarding or consent files. Invalid config files are preserved and reported instead of being overwritten.

## Updating
- Setup-installed launchers receive the complete update automatically at startup or their next scheduled check and restart when idle.
- Older standalone EXE installations need TheLadsClient-win-Setup.exe once.

## Verification
- Launcher regression tests cover new profiles, repeat preparation, existing preferences, legacy flags and invalid configuration preservation.
- Focused Minecraft 26.2 and 26.3 startup checks read the actual mods' in-memory settings and capture the rendered title screen. These offline QA runs do not verify Microsoft sign-in.
