# Lads Client 1.12.2

Lads Client 1.12.2 is a small fix update.

## Highlights

- **Lads badge in the tab list** (1.8.9, 1.20.1, 26.3): the Lads Client icon now sits to the left of the player's head instead of between the head and the name, and it shows the whole icon on 26.3.

## Added

- Nothing in this update.

## Changed

- **Tab list badge position**: when someone in the list uses the Lads Client, the list gets a small icon column on the left. Lads players have the icon there, everyone else's row keeps the space empty, so all heads and names stay lined up.

## Fixed

- **Broken Lads badge on 26.3**: the tab list drew only the top-left corner of the icon, so it looked like a few stray pixels. It now draws the full icon.
