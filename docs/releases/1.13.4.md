# Lads Client 1.13.4

Lads Client 1.13.4 redesigns the Lads Mods menu, adds side-by-side columns and drag reordering to the worlds list, lets you pick the title panorama from any Minecraft version, and brings the new Screenshots screen to 1.8.9.

## Highlights

- **Rebuilt Lads Mods menu**: a new Home page, 12 categories, fold-out groups, compact module rows, and a search bar that finds individual module settings by name.
- **Title screen panoramas & backdrop**: pick the title panorama from any Minecraft release, or turn Panorama off for a simple animated sky-and-water backdrop with a burgundy wave.
- **Better worlds & screenshots**: 1, 2 or 3 columns with drag-to-reorder in Singleplayer, newest-first screenshots, and the full Screenshots manager on 1.8.9.
- **Menu icons & polish**: Flaticon icons across game and options menus, consistent window titles across every version, and a cleaner launcher home card.

## Added

- **Panorama from any version**: choose any Minecraft release in Title Screen settings to download and display its title panorama, or toggle Panorama off for the simple background with its burgundy wave.
- **Worlds list columns and drag reordering**: show 1, 2 or 3 columns on the Singleplayer screen and drag worlds to reorder them with a live gap preview.
- **1.8.9 Screenshots screen**: 1.8.9 now uses the same Screenshots manager as newer versions, with grid previews, zoom, copy, save-as, and delete.
- **Menu button icons**: Flaticon icons now appear on menu and option buttons across all five versions wherever the label fits.

## Changed

- **Modules menu**: organized into a Home page, 12 categories, fold-out groups, and compact rows, with search matching both modules and their settings.
- **Title screen & server list**: the Legacy layout uses the classic one-line logo, the network button is now labeled "The Lads Network", and the pinned server row shows a yellow star instead of `[PINNED]`.
- **Screenshots order**: the Screenshots screen now lists your newest screenshots first.
- **Window titles**: all five versions now use the format `The Lads Client - <MC version> - 1.13.4 - <activity>`.
- **Launcher card & signing**: the `Play The Lads Network` button and player count sit below the card artwork instead of overlapping it. The launcher now also trusts a second release-signing key, so future updates can move to a new key.

## Fixed

- **O key in Friends**: pressing `O` while typing in the Friends screen search box or text fields no longer closes the screen.
- **Legacy title logo**: the one-line logo on the Legacy title layout is no longer cropped at the left and right edges.
- **Window title resets**: other mods can no longer overwrite the Lads Client window title after it is set.
- **1.8.9 worlds list dragging**: scrolling and dragging worlds on 1.8.9 now applies cleanly without failing on the world list hook.
