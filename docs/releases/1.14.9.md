# Lads Client 1.14.9

Server menu pages can now hold the view still: the world no longer moves while you move the mouse in a menu, only the cursor does.

## Added

- On a server menu page that asks for it, the camera stays frozen while the page is open. The cursor still follows the mouse at the same speed, and hover and click work as before. When the page closes you are looking exactly where you looked before it opened.
- Works on 26.3. Other versions keep the old behaviour (the view turns with the cursor).

## Notes

- Nothing is saved and nothing changes after you leave the server.
