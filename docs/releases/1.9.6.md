# Lads Client 1.9.6

Lads Client 1.9.6 lets modules keep their own background when global backgrounds are off, and fixes invisible Keystrokes presses.

## Highlights

- **Per-module backgrounds.** Turning global backgrounds (Plates) off no longer hides backgrounds you set manually on a module.
- **Keystrokes press flash.** Key presses now always flash, even with backgrounds off.
- **Zero SMP is public.** Anyone can install Zero SMP from the Experiences tab; the server is added to your list automatically.

## Added

- **Zero SMP for everyone**: the invite-only limit is gone. Installing or launching Zero SMP adds its server to your server list, and Auto Join is on by default (an existing Off choice is kept).
- **Manual module backgrounds with Plates off**: a module with its own Background color keeps it when global backgrounds are off. Modules using the global color still hide theirs.

## Changed

- **Scoreboard background**: the Scoreboard's own Background choice (black, white, or clear) now applies even with global backgrounds off.

## Fixed

- **Keystrokes**: with backgrounds off, key presses were invisible. The press flash now always shows.
