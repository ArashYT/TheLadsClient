# Lads Client 1.7.5

Kill banner FX timed exactly as the game plays them.

## Highlights
- **The FX flipbooks now land when Valorant's do.** 1.7.4 started every flipbook (the hero flame, the tier sparks, the ace's bursts) the instant the banner's FX event fired. The game's sprite widget shows a flipbook's first frame one timer tick later, and measured frame by frame against Oni's preview footage every FX frame lands 50 ms after its event-relative time. The client now plays them with that delay, so the flame and sparks overlay the real footage almost pixel for pixel (same placement, same burst radius, same spread).

## Added
- `tools/killbanner/preview_motion.py` draws the FX flipbooks too (tinted, mirrored, timed as the client does), so a skin's banner can be checked against its preview video with the FX in; `artifacts/1.7.4/analysis/fx-check` holds the Oni check (fine-step sheets, mask overlays).

## Changed
- Kill banner FX flipbooks start 50 ms after the banner's FX event (`KillBannerFx.FIRST_TICK`), as in the game.

## Fixed
- Kill banner sparks and flames no longer run about three frames ahead of the pips lighting up and the headshot flash.
