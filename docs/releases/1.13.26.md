# Lads Client 1.13.26

Smoother duels on The Lads Network: no clouds and a steadier HUD.

## Added

- **Hide Clouds** (Visuals > World): stops drawing clouds without changing your own Clouds video setting. The Lads Network turns it on during duels.

## Changed

- Servers using the Lads Client API can now cap how often the Lads HUD redraws. The Lads Network uses 60 per second in duels to keep more FPS for the game. Your own HUD FPS setting is not changed.
