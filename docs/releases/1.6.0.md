# The Lads Client 1.6.0

## Highlights
- **Three new launcher tabs: Skins, Modpacks and Servers**, plus Shader Packs and Data Packs pages and a Controls page in Settings.
- **Lads Zoom has been rewritten** and is now the only zoom. Essential's and OptiFine's zoom keys no longer stack on top of it.
- **1.7 Animations items are 1.7's real size.** In 1.5.1 they were drawn twice as big on 1.8.9.
- **Minecraft 1.21.1 is no longer supported.** The Lads Client now focuses on 1.8.9, 26.2 and 26.3.

## Added
- **Skins tab.** Keep a library of skins, imported from a PNG, a player name or an https link. Each skin can be classic or slim. One click applies a skin and cape to your Microsoft account, and you can save skin and cape pairs as combos. Offline accounts keep using a local skin as before. The skin editor has moved here, and the Accounts page is now a single column.
- **Modpacks tab.** Browse Modrinth modpacks, import a `.mrpack`, or create your own. Each modpack is a separate instance with its own folder and never gets Lads Core. You can play, manage mods, change the name, icon and RAM, or move to another pack version; updates keep your worlds, the files you changed and the mods you switched off. Fabric, Quilt, Forge and NeoForge packs are supported.
- **Servers tab.** Lists well-known servers with live player counts, MOTD and icons, and has a search. Add a server to the shared server list (used by every Lads version) or to a modpack's own list, and remove servers from either.
- **Server names fill themselves in.** Type an address into Add Server, in game (1.8.9, 26.2, 26.3) or in the launcher. A known server (84 are listed, such as Hypixel and CubeCraft) gets its proper name, and any other domain gets a tidy guess (play.example.com becomes "Example"). A name you type yourself is never replaced.
- **Shader Packs and Data Packs pages** under Packs. Browse Modrinth (and CurseForge, if you have a key), then install into a Lads version or a modpack. Data packs go into the world you pick, and 1.8.9 is left out because data packs need 1.13 or later. Every download is checked before it is installed, and Remove sends packs to the Recycle Bin.
- **Update resource packs** button: replaces your resource packs with their newest builds for the version you pick and keeps them switched on in every version's settings.
- **Settings → Controls.** Set FOV, sensitivity, render and simulation distance, max FPS, GUI scale, VSync and every key bind for a profile without starting the game. Key conflicts show in red. Nothing is saved while that profile's game is running.
- **1.8.9: Controls search.** The Controls screen gains a search box (Ctrl+F) that matches names, `category:` and `key:`, plus Show Conflicts, Show Unbound and Reset All (which asks to confirm).
- **1.8.9: smooth scrolling** in every list: servers, worlds, resource packs, controls, languages, options and Lads Screenshots.
- **Halloween theme**, with orange accents, purple chrome and a pumpkin-orange Play button.
- Installed Mods shows two columns with each mod's icon.

## Changed
- **Lads Zoom** on 1.8.9, 26.2 and 26.3:
  - Smooth Zoom moves at the same speed at any frame rate and stops exactly on the target.
  - Each scroll notch zooms 1.25x further (1.25x to 20x). The scroll wheel is only taken over while you are zoomed in, so the hotbar scrolls normally otherwise.
  - New options: Hold or Toggle mode, and Hand Zoom (whether the held item zooms too).
  - The mouse slows down as you zoom in. Opening a screen, clicking away or dying zooms back out.
  - Essential's and OptiFine's zoom keys do nothing while Lads Zoom is on, and work normally when it is off.
  - On 1.8.9, zoom no longer triggers while you type a C in chat.
- **1.7 Animations held items** are now the size 1.7.10 drew them, on every version. That is also about the size vanilla 1.8.9 and current versions draw them.
- **Legacy Swing** shows whenever 1.7 Animations is not in a use pose (placing blocks, attacking, holding an item). Blocking, bow and eating keep 1.7's own swing, so blockhitting still works.
- **Settings save automatically**, half a second after you stop typing. The Save buttons are gone. An invalid Microsoft client ID, Fabric version or API address shows an error under the box and keeps its last good value.
- Window buttons now say "Aspect Ratio: Free" / "Aspect Ratio: 16:9" and "Reset Size". Maximize and restore animate, and with the 16:9 lock on, maximize fills the largest 16:9 area. The close button fades to red.
- The Settings Behavior section uses two columns.
- **Minecraft 1.21.1 is no longer offered.** If 1.21.1 was your selected profile, the launcher now starts on 26.3. Your 1.21.1 profile entry, its game folder, worlds and settings are left untouched; they are simply no longer listed. 1.21.11 still installs as it did, but it gets no new testing: everything in this release was checked on 1.8.9, 26.2 and 26.3. Modpacks for 1.21.1 can still be installed from the Modpacks tab as separate instances.

## Fixed
- **CurseForge search always said "No results found."** CurseForge refuses requests that have no API key, and the launcher hid that error. It now says why there are no results (missing key, refused key, offline). Results are sorted by popularity and use the right loader (Forge for 1.8.9). The real author is shown, and files whose author forbids third-party downloads are never downloaded.
- **1.8.9 with OptiFine: Lads Zoom had no key.** OptiFine unbinds every other key on C when it starts, which left zoom unbound. Lads Zoom now keeps C.
- **Double zoom with Essential:** zooming with both Lads Zoom and Essential's zoom multiplied the two together.
- The skin editor did not load existing skins.

## Known limitations
- **Skins:** applying a skin or cape to a Microsoft account has so far been tested only against a stand-in for Minecraft's skin service. Your first Apply is the first real test, so tell us if it fails. Previews are a flat front view, not 3D.
- **CurseForge** browsing and pack updates need a CurseForge API key, entered in Mod Manager Settings. None is built in yet.
- **Update resource packs** uses one shared folder for every version, so a pack made for several versions (such as Faithful) switches to the build for the version you picked and may then show as incompatible in another version.
- Shader packs and data packs are installed in the right folders, but loading them in game has not been tested yet. Controls settings use the same format the game writes, but have not yet been checked in a running game.
- **Modpacks:** Quilt packs and Forge packs for 1.7.10 and 1.12.2 install, but none was launched in testing. A Forge 1.8.9 modpack you create uses Forge's recommended build (11.15.1.1722), not the build Lads 1.8.9 runs on.
- **Servers:** every Lads version shares one server list, so the Servers tab offers that list plus one per modpack. Lunar Network is not in the known-server list.
- **Zoom on 1.8.9** reads its key once per game tick, so zooming can start up to 50 ms after you press it (the zoom animation itself runs every frame). Hand Zoom is on by default, so the held item zooms off screen. Toggle mode, Smooth Zoom off and Hand Zoom off have unit tests but were not tried in game.
- The maximize animation was checked by window position only. It has not yet been checked by eye on a real monitor for flicker.
- **1.7 Animations:** item size was matched against Minecraft 1.7.10's code, since the test setup cannot run real 1.7.10. The 1.8.9 eating, drinking and red-armour poses were not captured again with this build.
- The full 1.8.9 in-game self-test has not been run on the combined 1.6.0 build. Each 1.8.9 change passed its own checks in its own test run, but several runs stopped early on checks that need keyboard and window focus while the test computer was in use.
