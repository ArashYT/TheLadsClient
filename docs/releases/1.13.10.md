# Lads Client 1.13.10

A small update: the Friends buttons are always visible and modpacks get Fabric API by themselves.

## Highlights

- **Friends buttons** Join, Invite and Chat are outlined so they always show, and Invite has its own green button.
- **Fabric API installs itself** for modpacks that need it for The Lads Core.

## Added

- **Fabric API auto-install**: a Fabric or Quilt modpack with The Lads Core turned on but no Fabric API gets the newest release from Modrinth (checked against Modrinth's hash) when the pack is installed, updated, saved in Manage, and before each launch. Modpacks without Fabric API now default to The Lads Core on.

## Changed

- **Friends screen**: the Join, Invite, Chat and "..." buttons have an outline and a lighter fill so they read on every row. Invite is green.

## Fixed

- **Lads Core toggle**: it was greyed out for a pack with no Fabric API; it can now be turned on and the launcher adds Fabric API.
