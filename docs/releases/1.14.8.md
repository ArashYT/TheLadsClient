# Lads Client 1.14.8

Servers can now hide the crosshair on their own menu pages and keep the "limits Lads settings" toast quiet while they do.

## Added

- Servers can hide the vanilla crosshair completely while a menu page is open, even when the Crosshair module is off. It comes back as soon as the server lifts the rule. Works on 1.8.9, 1.20.1 and 26.3.
- Servers can send a rule update without the "Lads Server limits N Lads settings" toast, and a toast that is already showing closes.

## Notes

- The toast still shows when a server lifts a safety block, so that stays visible.
- Not related to your own Crosshair settings: nothing is saved and nothing changes after you leave the server.
