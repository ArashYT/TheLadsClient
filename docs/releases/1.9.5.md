# Lads Client 1.9.5

Lads Client 1.9.5 introduces crosshair profiles, fewer game hitches, and fixes across sound playback, Server Discovery, and HUD profile saving.

## Highlights

- **Crosshair profiles.** Save, load, and switch between custom crosshair designs directly from the Crosshair settings page across 1.8.9, 1.20.1, and 26.3.
- **Fewer hitches.** Removed file I/O on the game thread for combo and kill sounds, prevented repeated re-downloads of missing server icons, cached 26.3 shulker previews, optimized texture-pack HUD and crosshair settings rendering, and eliminated periodic pauses in Thread Priority.
- **Animation and display fixes.** Restored the cut-short exit animation for the kill banner, ensured UTF-8 encoding for non-English HUD profile names, and prevented crashes when opening screenshot paths in 1.8.9 chat.
- **Client cleanup and network accuracy.** Outgoing web requests now report the accurate client version, Server Discovery operations are fully thread-safe, and non-functional FPS options were removed.

## Added

- **Crosshair profiles**: save, load, and switch crosshair designs from the Profiles row on the Crosshair settings page on 1.8.9, 1.20.1, and 26.3.

## Changed

- **Exordium settings**: removed the non-working FPS options from the client menu (the Exordium mod keeps its own settings screen).
- **Internal cleanup**: removed unused code and duplicate implementations across 1.8.9, 1.20.1, and 26.3.

## Fixed

- **Combo and kill sound hitches**: audio trim metadata is cached so combo and kill sounds no longer read files from disk on the game thread.
- **Server Discovery icon retries**: missing or failed server icons are no longer re-requested every frame.
- **26.3 shulker previews**: cached shulker item container summaries to avoid copying item stacks every frame.
- **Texture-pack HUD and crosshair settings**: reduced per-frame overhead and string allocations in texture-pack HUD rendering and crosshair settings.
- **Thread Priority pauses**: replaced full thread stack trace dumping with thread group enumeration to stop pausing the game once a second.
- **Kill banner exit animation**: cut-short exit animation now plays when a new kill replaces a banner currently on screen.
- **HUD profile character encoding**: profile configurations now save using UTF-8 so non-English layout names are preserved.
- **1.8.9 chat screenshot crash**: handled null parent directory paths when clicking chat screenshot links.
- **1.20.1 Server Discovery thread safety**: protected concurrent server discovery sets against simultaneous network, icon, and render thread access.
- **Web request client version**: web requests now report the real client version.
