# Lads Client 1.12.0

Lads Client 1.12.0 is a security, stability and polish update. Share codes, lads:// links, accounts and updates are locked down, the launcher survives crashes and bad files instead of losing your data, several multiplayer and 26.3 bugs are gone, and Lads SMP gets a round of exploit and data-loss fixes. The anti-ban changes from 1.11.2 are not repeated here.

## Highlights

- **Share codes are safe to import** (settings): A code from a stranger can now only change visual options. It can no longer carry file or sound paths (these could leak your Windows login hash to another computer), chat macros, Auto GG or other automation.
- **Safer links, accounts and updates** (launcher): lads:// links only work for your own Windows user and ask before acting. The launcher no longer deletes other launchers' saved accounts. Updates check their signature before downloading, and game Java options that could load outside code are blocked.
- **Your data survives** (launcher): Profiles save safely with a backup, a crash or an unexpected error no longer closes the launcher, auto-relaunch stops crash loops, and modpacks can no longer overwrite your settings.
- **Multiplayer fixes** (1.20.1, 26.3): 26.3 LAN worlds now show a real port, P2P games stop resending packets for no reason, and a late join request can no longer pull you out of your server.
- **Lads SMP exploit and data fixes** (Lads SMP): Cosmetic Armor can no longer duplicate items, The imfast speed option is off by default, hanging decorations no longer delete blocks, and Snail Mail no longer loses items.

## Added

- **Discord cape link** (cosmetics): Type `/link` in Discord with your six-character in-game code to unlock the Discord cape.
- **Confirmations** (launcher): Deleting an account or profile, signing out of Microsoft, closing a running game or Close All, and uploading to Imgur now ask first. The Imgur delete link is kept and shown.
- **Recycle Bin** (launcher): Deleted resource packs, shader packs, data packs and worlds go to the Windows Recycle Bin so you can restore them.
- **Force update check** (launcher): The update button can check for a new version right away.
- **Cancel and stall protection** (launcher): Zero SMP and Lads SMP Reborn downloads have a Cancel button, and a frozen download stops after 60 seconds instead of hanging.
- **Screenshot paging and log search** (launcher): The gallery loads screenshots in pages with a Show More button, and the log viewer has a search box. Live log updates pause while you select text.
- **Unsaved files warning** (launcher): The launcher asks before closing if the built-in file editor has unsaved changes.
- **Sign in again** (launcher): The Accounts page has a visible Refresh button and a Sign in again button, and works with the keyboard.

## Changed

- **Microsoft sign-in** (launcher): Only genuine Microsoft links are opened. The link and code are shown with Copy buttons. Signing in with a different Microsoft account than the one you chose no longer keeps that account.
- **Accounts for Zero SMP, Lads SMP Reborn and modpacks** (launcher): The in-game account switcher lists your launcher accounts. The game can no longer create an offline account in release builds, and modpacks require a signed-in Microsoft account.
- **Share codes and imports** (settings): Importing a code or loading a profile keeps your last three "Before import" backups, and no longer re-applies old one-time resets (Better F3, Keystrokes, Cloud Height, kill banners).
- **Updates and closing** (launcher): A launcher update or closing to the tray now waits for running Zero SMP or Lads SMP Reborn games and installs.
- **Modpacks** (launcher): Packs can no longer write Lads' own files (settings, accounts, server bypass list). A pack with a far-future file date can no longer override your settings, and Mrpack updates keep the right file variant.
- **New profile** (launcher): A dropdown of playable versions with Fabric as default.
- **Launcher speed** (launcher): Animations pause while minimized, in the tray or in game. Folder sizes, icons, screenshots and mod search load without freezing the window, and the 3D skin preview uses less memory and idles at 30 FPS.
- **Logs** (launcher): Log files rotate at 4 MB, and copy or share only sends the recent part.
- **Privacy** (backend): Shared configs no longer store a hash of the creator's IP address, and crash reports are kept for a limited time with rate limits.
- **Server owners (LadsClientAPI)**: `/ladsapi set` supports multi-word module names, rules sync again when players change world or proxy server, and unlisted modules keep the client default instead of being unlocked.
- **Lads SMP**: Parkour and Cut-through follow the server rules like other risky features, and claims now protect against buckets, hanging signs and hoe harvesting.

## Fixed

- **Crash catcher and tray** (launcher): The crash dialog and join links no longer close the launcher when it sits in the tray, and unexpected errors are logged and shown instead of ending the launcher.
- **Modpack settings overwritten** (launcher): The pack patch engine no longer wipes a mod config it cannot read or cuts options.txt short.
- **CurseForge imports** (launcher): Imports install into the correct game folder (older imports are moved in) and fail with a clear list of missing mods instead of reporting success.
- **Game repair** (launcher): Repair only says it succeeded when every file is verified.
- **Corrupt files** (launcher): Damaged profiles are restored from backup, and a broken Lads config is kept as a copy instead of being replaced.
- **Crash loops** (launcher): Auto-relaunch stops after two relaunches in ten minutes and tells you why.
- **Launch errors** (launcher): Problems before launch now show a message instead of silently re-enabling Play. Discord status no longer fails with an elevated Discord.
- **Colors and scaling** (launcher): Invalid hex colors in profile icons and loading screens no longer crash, loading screen colors are applied, and a high UI scale keeps the window on screen.
- **Modpack installs** (launcher): A finished install is no longer thrown away because an icon download stalled.
- **26.3 LAN hosting** (26.3): Open to LAN publishes a real port so friends can join.
- **P2P games** (multiplayer): Ping was measured wrong, so most packets were resent too early. P2P is now smoother on slower connections.
- **Join requests** (multiplayer): A late accept no longer pulls you out of a server. You are asked first, and friend and join errors are shown.
- **Jade crash** (26.3): No crash when the real Jade mod is installed, and the built-in Jade follows the server rules.
- **Entity culling** (1.20.1, 26.3): Mobs and chests no longer stay hidden while you stand still after breaking a block in front of them.
- **Memory and Smooth Biomes** (1.8.9): Fixed a memory leak when reloading resources, Smooth Biomes OFF is faster, clouds update after a reload and the OptiFine chunk update setting works again.
- **Text width** (1.20.1, 26.3): HUD text sizes follow the Force Unicode Font setting right away.
- **Multiplayer Options** (multiplayer): No more small stutters from reading files every frame.
- **Capes** (cosmetics): Remote cape downloads have timeouts and size limits, and a missing cape link no longer stops other capes.
- **Lads SMP: Cosmetic Armor** (Lads SMP): Fixed item duplication, creating any item and a crash on death.
- **Lads SMP: imfast** (Lads SMP): Off by default, and no longer removes the server's movement limits.
- **Lads SMP: decorations** (Lads SMP): Hanging decorations no longer replace real blocks or build where you are not allowed.
- **Lads SMP: Snail Mail** (Lads SMP): Mail is saved with the world, checked for a real recipient and delivered, so items are no longer lost.
- **Lads SMP: other** (Lads SMP): Death backups restore your equipment, dismantling a target dummy drops its gear, named villagers no longer drop a name tag, and saves are safer if a file is damaged.
