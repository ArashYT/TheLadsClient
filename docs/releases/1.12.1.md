# Lads Client 1.12.1

Lads Client 1.12.1 is a small maintenance update. The bundled mods are updated to their newest versions that we checked as safe, and a few launcher bugs are fixed.

## Highlights

- **Updated mods** (1.8.9, 1.20.1, 26.3): 18 bundled mods are updated to their newest stable versions with bug fixes from their authors.
- **Resourcify works with CurseForge again** (1.8.9): CurseForge now requires a newer Resourcify to download packs. Resourcify 1.6.2 fixes this.

## Added

- Nothing in this update.

## Changed

- **26.3 mods**: Fabric API 0.165.0, Lithium 0.26.3, JEI 31.14.0, MezzConfig 0.6.10, 3D Skin Layers 1.11.4, Better Statistics Screen 5.8.0 with TCDCommons API 5.8.0, MRU 1.0.44, Ixeris 4.6.11, Architectury 22.0.5, Collective 8.72 and Fabric Language Kotlin 1.14.2.
- **1.20.1 mods**: Ixeris 4.6.11, MezzConfig 0.6.10, Collective 8.72 and Fabric Language Kotlin 1.14.2.
- **1.8.9 mods**: Resourcify 1.6.2 and ReplayMod 2.6.24. ReplayMod now works with mods that react to key releases.
- The launcher replaces the old copies of these mods by itself the next time you play. Mods you added yourself are not touched.

## Fixed

- **CurseForge modpacks**: when files are missing, the error now lists every missing mod instead of only the first one.
- **Modpacks**: packs no longer carry over saved launcher state files in their Configured Defaults, and a pack's own loading screen colors are used when you launch it.
