# Lads Client 1.13.5

Lads Client 1.13.5 resolves issues with the Start Hosting button across game versions, adds friend skin heads with face and hat layers in the Friends tab, and optimizes startup performance on modern Minecraft versions.

## Highlights

- **Start Hosting Fixed**: Fixed the Start Hosting button across all versions so players can seamlessly host worlds for their friends.
- **Friend Skin Heads**: Friends screen now renders player face and hat layers asynchronously with Steve/Alex fallbacks.
- **Startup Optimizations**: Streamlined early mod initialization on Minecraft 26.3 to reduce loading times to the title screen.

## Fixed

- **Start Hosting**: Resolved world publishing and bridge initialization issues that prevented worlds from opening to friends.
- **Friend Avatars**: The Friends list now displays skin heads with full 3D hat layers without sending any game-server packets.
