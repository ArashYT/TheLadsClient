# Lads Client 1.13.11

Modpacks install the libraries their mods need, and the Modpacks screens are tidied.

## Highlights

- **Missing libraries install themselves**: a Fabric or Quilt modpack whose mods need a library that is not in its mods folder gets it from Modrinth.
- **Cleaner Modpacks screens**: the Add Content browser is opaque with working Provider and Sort boxes, and the Overview card is tidier.

## Added

- **Automatic dependency install**: when a modpack is installed, updated, saved in Manage, or launched, the launcher reads each enabled mod's required mods and downloads the ones nothing provides (newest release for the pack's Minecraft version, checked against Modrinth's hash). Fabric API modules map to Fabric API. Forge and NeoForge packs are left alone.

## Fixed

- **Add Content browser**: the page behind it showed through, and the Provider and Sort boxes were empty until touched.
- **Overview card**: the RAM box had mismatched spinner buttons and the "Default" chip sat off the title line; the gap above the tabs is smaller.
