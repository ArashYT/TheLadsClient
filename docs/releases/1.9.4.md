# Lads Client 1.9.4

Lads Client 1.9.4 introduces HUD layout profiles, short share codes, and Zero SMP downloads. Save custom HUD setups and share them with friends using clean codes or offline fallbacks. Selectively import settings, undo changes at any time, or install Zero SMP directly from the launcher.

## Highlights

- **HUD layout profiles.** Save, load, rename, and delete custom layouts directly inside the HUD editor across all versions.
- **Short and offline share codes.** Generate clean short codes (such as LADS-7KQ2M9 via bot.arashyt.ca) with one click. If the server is unreachable, the client falls back to an offline code.
- **Selective profile importing and safe undos.** Choose whether to import Mods, Settings, or Both. Your current layout is saved to a "Before import" profile before applying new setups.
- **Secure and validated imports.** Imported codes are validated and strictly size-capped. Personal data like accounts, file paths, and keybindings is never exported or accepted.
- **Zero SMP invite downloads.** Zero SMP can be downloaded and installed from the Experiences tab when you are signed in with an invited Microsoft account; other accounts see it as invite only.

## Added

- **Zero SMP invite downloads**: Zero SMP can be downloaded and installed from the Experiences tab when you are signed in with an invited Microsoft account; other accounts see it as invite only.
- **HUD profiles management**: save, load, rename, and delete layouts via the Profiles button in the HUD editor.
- **Share code generation**: generate short share codes hosted through bot.arashyt.ca, with automatic fallback to full offline share codes.
- **Selective import options**: choose between importing Mods only, Settings only, or Both when applying a profile code.
- **Automatic rollback profile**: captures your active layout and mod states into a "Before import" profile prior to applying any imported setup.
- **Payload safety validation**: sanitizes and caps incoming profile payloads to prevent oversized data and keep personal configuration private.

## Changed

- **HUD editor toolbar**: integrated the Profiles button to manage and share HUD configurations directly from the editor.

## Fixed

- **Import dialog pluralization**: corrected the profile summary preview in the import dialog to display "1 module" instead of "1 modules".
