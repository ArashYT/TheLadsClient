# Lads Client 1.9.4

Lads Client 1.9.4 introduces HUD layout profiles and share codes, letting you save and organize custom HUD setups, share them with friends using clean short codes or offline fallback codes, selectively import mods or settings, and revert changes at any time.

## Highlights

- **HUD layout profiles.** Save, load, rename, and delete custom layouts directly inside the HUD editor using the Profiles button across all supported versions.
- **Short and offline share codes.** Share your layout with one click: "Copy share code" generates a clean short code (such as LADS-7KQ2M9 via bot.arashyt.ca), and falls back seamlessly to a self-contained offline code if the server is unreachable.
- **Selective profile importing and safe undos.** Choose whether to import Mods (on/off states only), Settings (HUD layout and module options), or Both. Your current configuration is automatically saved as a "Before import" profile before applying new layouts.
- **Secure and validated imports.** Imported codes are validated and strictly size-capped. Sensitive personal data—including accounts, file paths, and keybindings—is never exported or accepted.

## Added

- **HUD profiles management**: save, load, rename, and delete layouts via the Profiles button in the HUD editor.
- **Share code generation**: generate short share codes hosted through bot.arashyt.ca, with automatic fallback to full offline share codes when offline.
- **Selective import options**: choose between importing Mods only, Settings only, or Both when applying a profile code.
- **Automatic rollback profile**: captures your active layout and mod states into a "Before import" profile prior to applying any imported setup.
- **Payload safety validation**: sanitizes and caps incoming profile payloads to prevent oversized data and keep personal configuration private.

## Changed

- **HUD editor toolbar**: integrated the Profiles button to manage and share HUD configurations without leaving the editor.

## Fixed

- **Import dialog pluralization**: corrected the profile summary preview in the import dialog to display "1 module" instead of "1 modules".
