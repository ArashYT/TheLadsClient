# Lads Client 1.8.2

Server Discovery logos and live MOTDs across all supported client versions (1.8.9, 26.2, 26.3), launcher version selection in descending order from newest to oldest supported releases, full Modrinth and CurseForge search filters on all content discovery tabs, and enlarged tab navigation controls.

## Highlights
- **Server Logos & Live MOTDs**: In-game Server Finder (`ServerDiscoveryScreen`) now renders official 32x32 server logos and real-time 2-line MOTDs matching The Lads Launcher. Supported with native async background pinging and fast CDN fallback loading across **1.8.9, 26.2, and 26.3**.
- **Descending Version List for Modpacks**: Version selection for custom modpack creation in the launcher now displays all Modrinth-supported Minecraft versions in strict descending order (26.3 at the top down to oldest supported releases).
- **Modrinth & CurseForge Search Filters**: Added comprehensive filter dropdowns (categories, loaders, sorting options) across all content tabs in the launcher (Mods, Resource Packs, Shaders, Datapacks). CurseForge searches default to popularity sorting with seamless pagination.
- **Enhanced Tab Visibility**: Header navigation buttons ("Installed Mods", "Browse Mods", "Mod Setting Manager") are enlarged, bolded, and given clearer active state highlights for easier switching.

## Added
- Live server status pinging and icon resolution in `ServerDiscoveryScreen189.java` (1.8.9) and `ServerDiscoveryScreen.java` (26.2 and 26.3).
- Fast fallback CDN logo resolution via `https://api.mcsrvstat.us/icon/<address>` when servers have not yet responded to direct status ping.
- Formatted MOTD text wrapping rendering two styled lines with Minecraft formatting codes.
- `GameVersionPolicy.ModrinthGameVersions`: Comprehensive descending catalog of supported Minecraft versions for modpack authoring.
- Category, loader, and sort filter dropdowns across Modpack content management and pack browser screens in The Lads Launcher.

## Changed
- Server Discovery list items now display 32x32 icons in an inset container with names, category/address chips, and live MOTD status.
- Version dropdown ordering changed from arbitrary or ascending order to strict descending order.
- Top tab headers enlarged (`FontSize="15"` / `FontSize="16"`, `FontWeight="Bold"`) with improved spacing and active indicator contrast.
- CurseForge search integration defaults to `sortField=2` (Popularity) with category ID resolution.

## Fixed
- Fixed missing server icons and plain text descriptions in the in-game Server Finder.
- Fixed version selector ordering in custom modpack creation.
- Fixed inability to filter by categories or change sort orders when browsing add-on content from Modrinth and CurseForge.
