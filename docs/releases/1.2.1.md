# The Lads Client 1.2.1

## Added
- Automatic launcher updates using complete Windows packages, including runtime files and bundled client mods.
- Automatic restart after installation. While Minecraft or account sign-in is active, the downloaded update waits and installs automatically when they finish.
- An offline release-notes history in the launcher, shown after installing a new version and accessible from the sidebar.

## Included development changes
- Redesigned launcher interface with grouped navigation, settings, theme accents, and a refreshed Play page.
- Packages the current 1.21.11 and 26.2 client builds and their version-specific mod manifests.

## Fixed
- Replaced the old updater that copied only one EXE and could leave required files missing or out of date.
- Replaced release scripts with one versioned build and draft-release process. Every release requires its own reviewed patch notes.

## Installation
- Windows x64: run TheLadsClient-win-Setup.exe once to install this new updater. Future stable releases download, install, and restart automatically.
- Existing EXE-only installations require this one-time setup. Do not overwrite an older installation with only the new EXE.
- Accounts, profiles, worlds, and settings remain in their existing user-data locations.

## Known limitations
- Update checks require internet access. Failed checks or downloads are logged and retried automatically.
- Live Microsoft authentication, authenticated multiplayer, and every in-game module were not revalidated for this release. Detailed feature limitations remain documented in the source repository.
