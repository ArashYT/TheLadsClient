# Lads Client 1.13.25

The launcher gets the game going faster and gives it more of the PC while it loads.

## Highlights

- **Faster Play**: the launcher remembers which mods it already checked, so the step from pressing Play to the game window starting takes about a second less (2.0 s → 0.7 s on our test PC).
- **More CPU while the game loads**: from Play until the game's sound engine starts (just before the title screen) the game runs at above-normal priority, then goes back to normal. It helps most when other programs are busy at the same time (browser, Discord, recording). If loading never gets that far, it goes back to normal after 2 minutes.

## Changed

- **Play page**: the banner is a slim strip at the top again, the profile, account and Play button stay at the bottom.
- The network card next to the banner title is no longer cut off in a small launcher window.
