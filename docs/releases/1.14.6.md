# Lads Client 1.14.6

Faster start and lighter loading.

## Added

- TheLadsBoost startup agent (on by default): speeds up startup on 26.3, 1.20.1 and 1.8.9. Warm start to title is about 17% faster on 26.3, 41% on 1.20.1 and 30% on 1.8.9. Cold start is about the same. Nothing changes in what the game shows or sends.

## Changed

- Launcher Play is faster: the mod scan is hash-cached and runs in parallel, and the mod snapshot and ModSync run after the game starts.
- 1.8.9 loads faster and uses less memory: the block atlas reads and mipmaps run in parallel, skins decode off the main thread, and duplicate models and quads are shared (heap about 212 MB to 198 MB).
- 26.3 Rentities uses ring buffers and reused staging buffers, and DynamicLights uses a per-section index, so less work per frame.
