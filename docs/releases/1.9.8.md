# Lads Client 1.9.8

Lads Client 1.9.8 delivers a major client-wide performance overhaul across rendering, resource pack switching, startup and world-join times, and launcher warm-boot speed, while fixing 26.3 Vulkan crashes and early-loading hangs, adding live startup progress to the early loading window, unifying screenshot chat action buttons and the Pause Menu `Screenshots` button across all versions, and hiding vanilla top-right potion icons when the Lads Potion Effects module is active.

## Highlights

- **Faster resource pack switching & `F3+T` reloads.** Selective asset-domain diffing (`PackAssetMask`) skips redundant sound engine teardown and shader/language/font reloads when switching texture-only packs, while eliminating Forge 1.8.9's double block/item atlas stitch and parallelizing CPU mipmaps.
- **Rendering, HUD & Inventory GUI speedups.** Enabled container screen batching on 1.20.1, added static 2D GUI quad caches (`ItemCull`), batched 1.8.9 tooltip boxes, cached Shulker Box NBT summaries, eliminated 60 Hz `glGetInteger` driver stalls on 1.8.9, and plugged a 150–400 MB `WorldClient` retention leak on 1.8.9 world switches.
- **Faster launches, world joins & live early-loading progress.** Enabled `QuickLaunch` by default, persisted extracted native DLLs across launches, cached mod JAR metadata and SHA-256 checks, added version-aware JVM GC flags, and upgraded the early loading window (`GameStartupSplash`) to show real-time startup stages and log activity.
- **26.3 Vulkan stability & unified Screenshots UX.** Fixed 26.3 Vulkan startup/HUD crashes, added all four screenshot chat buttons (`[Copy] [Open File] [Open Folder] [Upload to Imgur]`) and a Pause Menu **Screenshots** button across every version (`1.8.9`, `1.20.1`, `1.21.11`, `26.2`, `26.3`), and hid duplicate vanilla top-right potion icons when Lads `Potion Effects` is enabled.

## Added

- **Live early loading window status (`GameStartupSplash`)**: Displays both the current startup stage (`Starting Java Virtual Machine...`, `Initializing Fabric Loader...`, `Applying Mixin transformations...`, `Initializing Vulkan / OpenGL graphics backend...`, `Creating game window...`, etc.) and live activity details from process output and `latest.log`.
- **Pause Menu `Screenshots` button across all versions**: Added a first-class **Screenshots** button (`Slot.SCREENSHOTS`) to the Pause Menu in `1.8.9`, `1.20.1`, `1.21.11`, `26.2`, and `26.3` that opens the in-game Screenshots Gallery (with automatic folder fallback).
- **All 4 screenshot chat action buttons across all versions**: Taking a screenshot in `1.8.9`, `1.20.1` (Fabric & Forge), `1.21.11`, `26.2`, and `26.3` now consistently appends `[Copy]`, `[Open File]`, `[Open Folder]`, and `[Upload to Imgur]`.
- **Hide vanilla top-right potion HUD icons when `Potion Effects` is enabled**: When the Lads **Potion Effects** HUD module is enabled, the vanilla top-right status effect overlay (`Gui.renderEffects` / `Hud.extractEffects`) is automatically suppressed in `1.20.1`, `1.21.11`, `26.2`, and `26.3`.
- **Selective resource pack reload (`PackAssetMask`)**: Diffs changed resource packs by asset domain (`SOUNDS`, `LANG`, `FONTS`, `SHADERS`) and skips OpenAL `SoundEngine`/`SoundHandler` teardown, language metadata parsing, font reloading, and shader recompilation when unaffected by a pack switch.

## Changed

- **Resource pack menu & `F3+T` reload performance**:
  - Eliminated Forge 1.8.9's duplicate `TextureMap.loadTextureAtlas` pass during `Minecraft.refreshResources()` and parallelized CPU mipmap generation across worker threads.
  - Cached 1.8.9 `ResourcePackRepository.Entry.toString()` and relative subfolder paths to remove hundreds of thousands of `File.stat` and `String.format` calls when opening the pack screen.
  - Cached subfolder directory scans (`PackFolderHelper.findSubfolders`) and stripped lowercase search strings (`PackFilterHelper`) across `1.8.9`, `1.20.1`, and `26.3` so typing in the pack search bar never hits the disk.
  - Cached negative resource existence lookups in `EMFResourceCaching` (`1.20.1` & `26.3`) and hoisted sign/hanging-sign `ModelPart.bakeRoot()` outside the 1,232-iteration `BlockState` loop in `BakedBlockEntities1201`.
- **Rendering, HUD, and world frame-time optimizations**:
  - Enabled ImmediatelyFast `experimental_screen_batching` on `1.20.1`, added static 2D GUI south-quad caches in `ItemCull1201`, `ItemCull26`, and `Flerovium189`, and cached `ShulkerSummary1201` via `WeakHashMap<CompoundTag, ShulkerSummary1201>`.
  - Wrapped `1.20.1` Lads HUD rendering in `ImmediatelyFast` HUD batching (`NativeAutohide1201`), gated redundant depth-buffer clears in `HudPipeline1201`, and removed per-frame `GL11.glGetInteger` calls in `1.8.9` `HudBuffer189`.
  - Precomputed active light-source AABBs in `DynamicLights`, added an $O(1)$ fuse string table in `TntTimerModule`, added same-tick light caching and $O(N)$ particle list compaction in `ParticleCore`, and reused a `ThreadLocal<short[]>` queue in `1.8.9` `VisGraph`.
- **Startup, world join, and launcher warm-launch speed**:
  - Enabled `QuickLaunch` by default, brought `.lads-verified` warm launch fast-paths to `ModpackLauncher`, persisted extracted native DLLs (`ConfigureCachedNativesDirectory`), and cached `FabricModMetadata` and JAR SHA-256 lookups.
  - Cached `ClientPaths.getConfigFile()`, skipped redundant disk writes in `ConfigManager.load()` when already migrated, and moved `ProfileManager.onContext()` saves on world join to a background thread.
  - Fast-closed `ReceivingLevelScreen` on `1.20.1` and `26.3` as soon as initial level packets arrive without waiting for the 2-second fallback timer.
  - Upgraded `1.8.9` OptiFine installer support to `HD U M6_pre2` and retired obsolete `fzzy_config` and `no-resource-pack-warnings` jars on `1.20.1`.

## Fixed

- **26.3 Vulkan crashes**: Fixed `HudBuffer26` importing OpenGL textures into Vulkan and calling `GL11.glGetInteger` when running on the Vulkan backend, and fixed `MixinRenderSystem` (` ImmediatelyFast`) injecting into OpenGL-only methods on Vulkan.
- **26.3 early loading hang**: Replaced synchronous `File.AppendAllText` logging on the game's stdout pipe in `MainWindow.axaml.cs` with an asynchronous background log queue and automatic 4 MB log rotation, and removed malformed AppCDS path arguments on Java 25.
- **1.8.9 `WorldClient` memory leak**: Cleared `EntityCulling189` and `BakedBlockEntities` chunk/entity references on world unload and server switch, freeing 150–400 MB of retained heap across server hops.
- **Zero SMP parallel mod-loading thread safety**: Added synchronization guards for `DispenserBlock.registerBehavior`, `Registrate`, `Create`, `Create Deco`, and `Zeta` during parallel Forge mod initialization.
