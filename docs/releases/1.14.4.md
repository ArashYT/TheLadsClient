# Lads Client 1.14.4

Input, rendering and world-loading work on top of 1.14.3: Offhand Key, Instant Hotbar, Smooth Singleplayer, Player LOD, faster pack screen and the Lads API resend fix.

## Added

- Offhand Key: a key that swaps your offhand item. Blocked on servers that ban it or whose rules are unknown (same rule as every other feature).
- Instant Hotbar: hotbar slot changes apply at once.
- Smooth Singleplayer: smoother camera and movement in singleplayer and LAN.
- Player LOD: far-away players draw with fewer parts (trim, cape, items and outer layer by distance). Respects zoom and skin layers.
- Chunk priority, flush batching and a memory guard for the renderer.

## Changed

- The pack screen opens faster: pack icons load in the background.
- Server packs download in parallel on 26.3.
- Map frames use a faster path on 1.20.1 and 26.3.
- 1.21.11 and 26.2 are no longer built. The supported versions are 1.8.9, 1.20.1 and 26.3.

## Fixed

- Lads API: the resend policy after a world change is kept, so a respawn no longer wipes it.
- 26.3: the real Jade overlay stays below the Lads API notification and the Lads boss bar.
- 26.3: outline and OIT draws that hit a null pipeline are skipped instead of crashing.
- Launcher: the settings preview scrolls at high UI scale, and the Play label is not clipped.
