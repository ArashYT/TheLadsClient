# Lads Client 1.13.30

New profiles and modpacks start much faster the first time.

## Changed

- New profiles and modpacks no longer download Minecraft's game files (sounds, languages, textures) again when your PC already has them. The launcher reuses the copies another Lads profile, a modpack or the official Minecraft launcher already downloaded, checks each file, and on the same drive they take no extra disk space. A new 26.3 modpack now downloads a few megabytes instead of about 490 MB.
