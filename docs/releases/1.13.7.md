# Lads Client 1.13.7

A small launcher polish update.

## Highlights

- Easier-to-read launcher text and a cleaner Home and Experiences page.

## Changed

- **Readable text**: faint grey text in the launcher (Home, startup splash, Skins and Experiences pages) is brighter, so it is easier to read.
- **Home**: Launch is now the one main button; the Lads Network button is a quieter secondary button.
- **Status bar**: numbers no longer jiggle in width as they change.
- **Experiences**: removed the "OFFICIAL" tag from every card, since every pack on that page is official.
