# The Lads Client 1.4.5

## Highlights
- **A cleaner launcher.** The sidebar is regrouped, Mods and Packs are separate tabs, and the Play screen has bigger Profile, Playing as and Play buttons. The banner artwork now shows in full, and usage stats moved to a bar along the bottom.
- **The 1.8.9 camera moves again** with Raw Input on, and mouse input on 1.8.9 has less delay.
- **Borderless fullscreen is rebuilt on every version.** It is a normal window without a frame, sized to your monitor, so OBS, Discord and other window capture can see the game.
- **Chat messages no longer shake the screen.** Only the new message slides in.
- **One Chat module** holds every chat setting.

## Added
- **Packs tab.** It browses resource packs and opens the shared resource pack and shader pack folders.
- **Skin heads in "Playing as".** Each account in the Play screen's account picker shows its skin, including the selected one.
- **Smooth Hotbar on 1.8.9.** The selection frame glides between slots, at the same speed as on the newer versions.
- **Borderless fullscreen on 1.21.1 and 1.21.11**, which had none before.
- **Chat module options.** Background, Width, Height, Message Animations, Timestamps, Hide Signing Indicators and Screenshot Link Buttons are now all in one module, on 1.21.1, 1.21.11, 26.2 and 26.3. Your old "Chat timestamps" (Client Tools) and "Hide Chat Indicators" choices carry over. On 1.21.x, the screenshot buttons are Open File and Open Folder only.
- **Memory recommendation.** The launcher sets the game's maximum RAM from your PC's memory: 3 GB on 6 GB, 4 GB on 8 GB, 5 GB on 12 GB, 6 GB on 16 GB, and at most 8 GB. An amount you save yourself is kept.

## Changed
- **Sidebar order:** Play, Accounts and Profiles together; then Worlds (now with an icon), Mods, Packs, Gallery and Files; then Settings and Logs.
- **Play screen.**
  - The Game folder, Worlds, Resource packs, Shader packs, Screenshots and Manage accounts buttons are removed. Their pages are in the sidebar.
  - Profile, Playing as and Play are 1.5× taller, with larger text.
- **Version picker.** Newest version first, 1.8.9 last. Only 26.3, 26.2 and 1.8.9 can be picked; the other versions are listed but greyed out. The selected version has a red accent bar and bold text.
- **"Latest Release" follows the newest version** (now 26.3) instead of staying on 26.2.
- **The HUD FPS limit is off unless you turn it on**, on every version. The HUD updates every frame by default.
- **Legacy Swing on 1.8.9** plays the Legacy Console Edition swing, as on 26.x, without the re-equip dip.
- The command palette button is removed from the title bar; Ctrl+K still opens it. The Lads logo zooms in when you hover over it.

## Fixed
- **1.8.9: the camera didn't move in game** while the mouse worked in menus. Raw Input only listened to the first of several "mice" Windows reports. It now reads all of them, and it falls back to normal mouse input if none moves.
- **1.8.9 mouse delay.** The mouse is read right before the camera turns instead of a frame earlier, and the graphics driver can hold at most one queued frame.
- **1.8.9: the window couldn't be resized freely.** Leaving fullscreen removed the window's resize frame. Any window size works again.
- **Borderless fullscreen couldn't be captured.** It covered the monitor exactly, so Windows treated it as exclusive fullscreen. 1.8.9's borderless toggle also didn't work at all.
- **Chat animation moved the whole HUD** on every new message.
- **Chat Background off hid the closed chat entirely**; now it only removes the dark line backgrounds.
- Chat and Borderless Fullscreen were shown as unavailable in the 26.x module menu.

## Known limitations
- Borderless windows are 1 pixel larger than the monitor so Windows keeps them capturable. That pixel row (or column on 26.3) is off-screen, or on a neighbouring monitor.
- On 1.8.9, launching straight into fullscreen briefly uses exclusive fullscreen before switching to borderless.
- 1.7 Animations (block-hitting) and a Chat module are not on 1.8.9 yet.
