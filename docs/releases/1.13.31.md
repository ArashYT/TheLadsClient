# Lads Client 1.13.31

Server resource packs no longer stay loaded after a failed server switch.

## Fixed

- When a server sent you to another server and that switch failed (for example "Connection failed while transferring to the server" or "Failed to log in: Status: 429"), the first server's resource pack stayed loaded on the server list, the menus and the next server you joined. It now unloads as soon as the switch fails, like it does after a normal disconnect.
