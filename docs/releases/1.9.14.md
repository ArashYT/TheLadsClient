# Lads Client 1.9.14

Lads Client 1.9.14 is a big one: a **Cosmetics** button with the emote wheel and 9 free emotes, **accurate Hypixel ping**, **Hypixel Quickplay** and tab completion, **OptiFine's settings built into 1.8.9**, a round of **1.8.9 fixes** (freeze-free screenshots, a Java 25 startup crash, the HUD FPS cap, F11, the replaying sound), **Cloud Height** set to MAX, and **automatic slim/classic skin detection**.

## Highlights

- **Cosmetics button** (all versions): on the title screen and in the pause menu. Pick the emote in each of the wheel's 8 slots and switch emote sharing on or off. 9 free emotes: Groove, Wave, Clap, Floss, Cheer, Bow, Facepalm, Salute and Shrug, and every emote has its own key (Controls -> Lads Emotes). (The 1.9.12 notes announced this screen, but it only ships now.)
- **Accurate Hypixel ping**: the Ping HUD shows the lower of Hypixel's own ping and a server-list ping (Hypixel's adds up to 50 ms of server wait), as the median of the last 3 samples, every 5 seconds, and shows a number right after you join.
- **Hypixel Quickplay**: a key opens a game picker for every Hypixel mode, with up to 9 favourites and a Play Again key. Plus tab completion for Hypixel commands, game modes and player names.
- **OptiFine settings in 1.8.9**: Options -> Video Settings has OptiFine-style Quality, Details, Animations, Performance and Other pages, so you keep those settings without OptiFine.
- **1.8.9 fixes**: screenshots (F2) no longer freeze the game, a crash right at startup on Java 25 is fixed, the HUD FPS cap works, leaving fullscreen with F11 no longer leaves the picture in a corner, and closing a menu no longer replays the last sound.

## Added

- **Session Stats** (Hypixel): a HUD with this session's games, wins, losses, kills, final kills, deaths, beds broken and win streak; type `/session` for a summary in chat.
- **Bed Wars height limit** (Hypixel): shows how many blocks you can still build up, turning yellow and red near the limit.
- **Streamer Mode** (Hypixel): hides the lobby/server id and the date on the scoreboard and the "Sending you to ..." server names in chat.
- **Chat emotes for everyone** (Hypixel): `:shrug:`, `:tableflip:` and the other MVP++ chat emotes turn into their symbols when you send them.
- **Cloud Height** (all versions): a slider whose last step is MAX (256 on 1.8.9, the world's top on 1.20.1 and 26.3). On and at MAX for everyone once; your own setting sticks after that.
- **Coloured boss bars** (1.8.9): the boss bar takes the colour of the boss name (red, green, blue, yellow, purple, pink, white), like newer versions. Switch: Boss Bar -> Colored boss bar.
- **Coordinates "C"**: the Coordinates HUD can show the chunk count from F3 (Show C, off by default).
- **Faster 1.8.9 rendering**: faster clouds, a HUD cache and Fast Render for Ionium, and about 64 fewer OpenGL calls per frame. Up to +15-25% FPS on laptops.
- **Anonymous usage stats** (launcher): the launcher tells us once at start and every 6 hours that an install is in use (a random id, the launcher version and the game versions played; no names, accounts or IP addresses kept). Off in Settings -> Send anonymous usage stats.

## Changed

- **Keystrokes Clean style** follows the global colour by default and has its own colour pickers (key, pressed key, backgrounds). In a HUD group its buttons keep their size: only your own resize and the GUI scale change it.
- **Armor HUD** (hotbar slots look) uses the hotbar's two left and two right slots, so resource packs with decorated hotbar ends look right.
- **Mob kill banners** are on by default, and turned on for everyone once.
- **Smooth scrolling** scrolls 1.5x further per wheel notch in every menu.
- **Skin selector** (launcher and in-game) detects slim (Alex) or classic (Steve) arms from the skin by itself.
- **The launcher installs updates before it opens** (waits up to 10 seconds on the startup screen; offline it opens as usual).
- **1.20.1 and 26.3 performance**: frame pacing steps aside at very high frame rates, the minimap and HUD do less work per frame.

## Fixed

- **1.8.9 crash at startup on Java 25** (the game closed with no error while loading): a Java memory setting the launcher used is no longer passed to 1.8.9.
- **1.8.9 screenshots freeze the game**: the picture is saved in the background now.
- **1.8.9 HUD FPS cap had no effect**: changing numbers (FPS, coordinates) kept the HUD at 60 FPS; modules set to ignore the cap now update live.
- **1.8.9 F11**: leaving fullscreen with F11 drew the game in a small corner of the window.
- **1.8.9 sound replays when a menu closes**: a sound that had already finished played again.
- **Nametags in front third-person view** (1.8.9): names and floating text tilted the wrong way.
- **Tab list crash** with Show Player Count on servers that send no header or footer.
- **HUD overlaps**: the Potion Effects HUD, toasts on 1.8.9 and tooltips no longer overlap other HUDs.
