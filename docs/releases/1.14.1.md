# Lads Client 1.14.1

A crash-fix update for 26.2 and 26.3.

## Fixed

- Fixed a crash on NVIDIA graphics cards (Vulkan) that closed the game after a death, spectating or a kit change on the Lads Network (26.3).
- Fixed a crash on joining a world with Improved Transparency on (Effectual particles) (26.3).
- Fixed a rare crash when a monitor turned off or the resolution changed (26.2, 26.3).
