# The Lads Client 1.2.2

## Added
- Minecraft 26.3 support as the primary target, with matching HUD/module changes for 26.2.
- Boss-bar controls, a console-style legacy swing module, and Xaero minimap controls integrated into Lads. Xaero continues to provide maps, waypoints and server compatibility.
- HUD settings gears, right-click locking and centering, vertical toolbar docking, collapsed controls, and organized default positions. Choose Reset layout in the editor to apply the new arrangement to existing profiles.
- Custom skin customization with a live preview, controls search, and resource-pack compatibility filtering and sorting.

## Changed
- Coordinates use centered X/Y/Z labels with vertical or horizontal layouts. Armor shows item textures and inventory durability bars. Mouse CPS appears below the LMB/RMB labels.
- Dynamic FPS defaults to 60 FPS unfocused and 30 hidden; mode changes apply their presets. Vanilla Reduce FPS When is removed in favor of the module.
- Zoom defaults to C. Standard screenshots and the screenshot gallery use the global .minecraft/screenshots folder.
- First launch prefers Vulkan when compatible. With Iris installed, OpenGL is used to preserve shader support and avoid its Vulkan startup crash.
- Minecraft telemetry is disabled, and feedback, bug-report and player-report buttons are removed. Discord RPC is marked Coming soon.
- Updated 13 compatible mods in the 26.3 pack. Existing user layouts, bindings and FPS profiles are preserved.

## Fixed
- Disabled HUD previews no longer repeat overlapping labels. Every available HUD widget has a settings shortcut.
- Legacy vertical bobbing now updates at game-tick cadence and interpolates during rendering.
- Borderless window handling uses native SDL fullscreen on 26.3 and corrected desktop bounds on 26.2.

## Updating
- Installed v1.2.1 launchers automatically download this stable release, then install and restart when Minecraft and account sign-in are idle.
- EXE-only development copies need TheLadsClient-win-Setup.exe. Update checks require internet access and must not be disabled through LADS_SKIP_UPDATE.
- Accounts, profiles, settings and worlds remain in their existing user-data locations.

## Verification and known limitations
- 108 targeted HUD tests passed. The final 26.3 isolated world run passed 248 native feature checks and 50 HUD-editor checks, with actual rendered screen captures. The focused 26.2 run passed 25 requested-feature checks and 50 HUD-editor checks.
- Broader 26.2 nametag visibility, crosshair attack-indicator and render-scale checks remain unresolved. The focused pass does not certify those features.
- Physical Alt-Tab/window-edge behavior, live Microsoft authentication and multiplayer/Xaero server restrictions were not revalidated. Discord RPC remains unavailable.
