# Lads Client 1.8.0

Essential lockdown, native server discovery, responsive title screen scaling, in-game version switcher, quit confirmation, native screenshot preview, and account skin fixes.

## Highlights
- **Essential Mod Lockdown**: Essential has been stripped from all menus, options, and keybind lists. Settings are permanently locked: Game Activity sharing is ON; Chat Filter is OFF; Essential nameplate and tablist icons are OFF; 3rd-person nameplates are OFF; emotes, cosmetics, and telemetry are completely disabled.
- **Native Multiplayer Server Discovery**: Replaced Essential's Discover tab with a native server finder matching the launcher's server directory, featuring category tabs, instant search, live server ping/status, direct `[+ Add]` to server list, and direct `[Join]`.
- **Title Screen Scaling & Overhaul**: The main menu now locks to a consistent virtual scale 3.0 layout regardless of the Minecraft GUI scale setting. Slogan updated to "Is the sever up?". Added Replays and Friends buttons to the main grid; preserved the "More..." button while cleaning its inner screen; and added a sleek Language globe icon in the top-right header next to fullscreen.
- **In-Game Version Switcher**: Added a 2-column wide "Switch Versions" button directly below Quit Game. Players can select any installed version from a popup dialog, confirm, and the launcher automatically relaunches into that version seamlessly.
- **Quit Game Confirmation**: Added a confirmation screen with a redesigned door exit icon to prevent accidental exits.
- **Native Screenshot Preview**: Remade screenshot previews natively inside Lads Core with toast notifications showing image thumbnails and clickable chat actions (`[Copy]`, `[Open File]`, `[Open Folder]`, `[Upload to Imgur]`).
- **In-Game Account Switcher Fix**: Fixed the account switcher showing blue fallback faces by properly resolving player UUID skins and falling back to default Steve/Alex textures.
- **Multiplayer Background Polish**: Removed the dark dirt texture background behind the multiplayer server list for a clean, modern aesthetic.

## Added
- `ServerDiscoveryScreen.java`: In-game server browser reading curated servers from `thelads/known_servers.json` with search, category filtering, and direct connect.
- `VersionSwitchScreen26.java`: In-game version switching modal communicating with the launcher via `lads_versions.json` and `lads_next_version.json`.
- `QuitConfirmScreen26.java`: Clean exit confirmation screen with custom pixel exit icon.
- `NativeScreenshotToast.java`: Native screenshot capture toast displaying thumbnail preview.
- `EssentialConfigEnforcer.java`: Automatic enforcer ensuring privacy settings, disabled emotes/cosmetics, and disabled telemetry remain locked on launch.
- Language globe icon button in the title screen header bar.
- Replays and Friends main menu buttons directly on the primary button grid.

## Changed
- Title screen branding tagline updated to "Is the sever up?".
- Title screen UI rendering uses matrix scaling to maintain scale 3.0 proportions across GUI scales 1 through 4/Auto.
- Multiplayer screen strips dark list background behind server entries (`ServerListBackgroundMixin.java`).
- `TitleExtrasScreen26`: Filtered out Replays, Friends, and Language (now accessible from the title screen).
- Launcher: Added pre-launch Essential settings enforcement and automatic profile switching handoff upon game exit.

## Fixed
- In-game account switcher no longer displays solid blue face squares instead of player skins.
- Essential keybindings and categories no longer appear in Key Binds or Controls screens.
- Essential UI overlays suppressed from title screen, pause screen, and multiplayer screen.
