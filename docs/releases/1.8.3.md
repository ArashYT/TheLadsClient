# Lads Client 1.8.3

Launcher startup crash fix, sub-tab button enhancements, two-column accounts management layout, server-enforced Hypixel safety auto-disable policy, and polished server refresh ping animation.

## Highlights
- **Launcher Startup Crash Fix**: Resolved a critical `NullReferenceException` during XAML hydration where inline selection indices on add-content filter dropdowns fired events before control references were assigned.
- **Hypixel Safety Auto-Disable**: Strictly enforces Hypixel server compliance by automatically disabling blacklisted modules (`Minimap`, `XaeroMinimap`, `XaeroWorldMap`, `AutoReconnect`, `MouseTweaks`, `ReachDisplay`, `Jade`, `ShulkerBoxUtils`) when connected to Hypixel (`*.hypixel.net`, `*.hypixel.io`). Blocked modules are clearly badged in settings and cannot be toggled while connected.
- **Redesigned Accounts Screen**: Restructured the Accounts management interface into an intuitive two-column layout, placing action controls on the left and the account selection list on the right.
- **Enlarged Sub-Tab Navigation**: Enlarged navigation tabs ("Installed Mods", "Browse Mods", "Mod Manager Settings" and modpack detail tabs) with increased font sizing, padding, and higher contrast active indicators.
- **Polished Server Refresh Animation**: Server Discovery and 1.8.9 multiplayer ping animations now feature smooth pulsing indicator cycles and prevent MOTD or player count wiping during refreshes.

## Added
- `HypixelSafetyManager`: Centralized Hypixel server detection and disallowed-module policy preventing use of unfair gameplay elements on Hypixel network domains.
- In-game settings badges (`Hypixel Block`), blocked toggle state, and informative tooltips explaining server rule compliance.
- Unit test suite `HypixelSafetyTest` verifying module blocking, domain matching, and unblocked behavior on standard servers.
- Two-column responsive layout for the launcher Accounts page separating action buttons and account selectors.

## Changed
- Enlarged launcher TabItem styling (`FontSize="18"`, `Padding="26,14"`, `MinHeight="48"`) across Mods and Modpack management views.
- Upgraded global launcher tab styles to `FontSize="16"`, `Padding="20,12"`, `MinHeight="42"`.
- Modpack add-content filter initialization now safely defers event handling until controls are fully hydrated.
- Smooth pulsing dots animation on pinging states in `ServerDiscoveryScreen` and `ServerDiscoveryScreen189`.

## Fixed
- Fixed critical launcher startup crash (`NullReferenceException` in `ModpacksView.AddContentFilter_Changed`).
- Fixed server list flickering and MOTD blanking during refreshes on Minecraft 1.8.9.
- Fixed reconnection attempts and reach display remaining active when playing on Hypixel.
