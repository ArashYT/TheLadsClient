# Lads Client 1.13.32

A smoother launcher update screen, and two fixes for crashes and false crash reports.

## Changed

- The launcher's start-up and update screen now shows a smooth progress bar that climbs steadily from 0 to 100% without jumps, and slows down gently near the end.
- The pickaxe on that screen keeps animating the whole way, including while the update installs and the launcher restarts into the new version.

## Fixed

- Opening your inventory or a chest on The Lads Network lobby on 26.3 no longer kicks you out of the world when the JEI mod fails to start there. JEI is skipped on that server and works normally everywhere else.
- A game that is closed with exit code -1 is no longer reported as a crash.
